## Calendrier

L'**An 0** = **L'Arrachement**. L'evenement le plus marquant de l'histoire mortelle.

- **av.A** = avant l'Arrachement
- **ap.A** = apres l'Arrachement
- Annee actuelle : **~10 200 ap.A** (a ajuster selon les calendriers des nations)

Les dates anterieures aux mortels (~45 000 av.A) sont des estimations — personne ne sait combien de temps a dure la Genese.

## ERE 0 — LE VIDE

Avant tout : rien. Pas de temps, pas d'espace, pas de matiere.

Une **resonance** apparait dans le neant. Elle produit les 5 Eternels en cascade :

1. **Celestia** — lumiere, ordre, structure. Donne au Vide une direction : le haut.
2. **Noctis** — ombre, mystere, profondeur. Donne le contraire : le bas.
3. **Tempora** — flux, changement. Cree le *avant* et le *apres*. **Le temps commence.**
4. **Eldoria** — matiere, substance. Tisse les premieres etoiles depuis le Vide.
5. **Navigor** — chemins, connexions. Relie tout : dimensions, plans, Eternels entre eux.

A ce stade : pas de monde physique. Un cosmos en formation, un ciel d'etoiles naissantes, 5 entites.

## ERE I — LA GENESE (millions d'annees → ~45 000 av.A)

> **Fichier detaille :** [Chronologie_Era1.md](Chronologie_Era1.md)

### Les 12 Cosmiques

Apparaissent en 4 phases sur des centaines de milliers d'annees :

**Phase 1 — Les Fondamentaux** (un monde physique)
1. **Terranu** (terre, pierre) — la matiere s'organise en sol, roche, montagnes
2. **Aquor** (eaux) — les premiers oceans remplissent les creux
3. **Aerion** (vent, ciel) — une atmosphere se forme

**Phase 2 — Les Dynamiques** (le monde vit)
4. **Gravitas** (gravite) — marees, orbite, poids
5. **Climata** (saisons, climat) — cycles, temperature, pluie
6. **Flamara** (feu, transformation) — volcans, chaleur interne

**Phase 3 — Les Vivants** (la vie apparait)
7. **Arborius** (vegetation) — plantes, puis forets entieres
8. **Spiritus** (souffle, ames) — le concept d'etre vivant nait
9. **Cantor** (harmonie, musique) — la vie s'organise en ecosystemes

**Phase 4 — Les Mystiques** (la conscience)
10. **Somnix** (reves, inconscient) — les premieres creatures revent
11. **Judicar** (justice, equilibre) — le concept de bien/mal emerge
12. **Transitum** (passages, mort) — le cycle vie/mort se ferme

### Origines des Cosmiques

| Cosmique | Ne de | Domaine |
|----------|-------|---------|
| Terranu | Eldoria x Tempora | Terre, pierre, montagnes |
| Aquor | Celestia x Noctis | Eaux, oceans, pluie |
| Aerion | Celestia x Navigor | Vent, ciel, atmosphere |
| Gravitas | Terranu x Noctis | Gravite, poids, marees |
| Climata | Tempora x Eldoria | Saisons, climat |
| Flamara | Eldoria x Noctis | Feu, volcans, transformation |
| Arborius | Eldoria x Celestia | Vegetation, forets, vie vegetale |
| Spiritus | Navigor x Celestia | Souffle, ames, etres vivants |
| Cantor | Eldoria x Arborius | Musique, harmonie, ecosystemes |
| Somnix | Noctis x Tempora | Reves, inconscient |
| Judicar | Celestia x Tempora | Justice, equilibre, morale |
| Transitum | Navigor x Noctis | Passages, mort, au-dela |

### Le Mont Originel et le Mont Jumeau

Le premier point d'ancrage physique du monde : le **Mont Originel** — pic de roche pure emergeant du chaos. Ce n'est pas cree volontairement — il se forme *parce qu'Eldoria existe*.

Un second pic emerge : le **Mont Jumeau**, de l'autre cote du futur Panghor.

Ces deux monts existent **encore aujourd'hui** :
- Le Mont Originel = le **Mont Cendra** (celui qui pulse dans le lore actuel)
- Le Mont Jumeau = enfoui sous les glaces ou au fond de l'ocean — perdu

### Les 45 Etheres

Naissent des interactions entre Cosmiques. 45 entites de 3eme rang, specialisees dans des forces tres precises (le gel, le tonnerre, le corail, la lave, les marees, les vents du nord, etc.)

Ils s'installent dans des lieux specifiques du Panghor, creant des **zones d'influence** qui deviendront les particularites geographiques des futurs continents.

*Exemples : Glacien (Climata x Aquor), Embrasur (Flamara x Terranu), Tempestal (Aerion x Climata), Lumiveil (Celestia x Aerion)...*

### Le Panghor — Supercontinent unique

A cette epoque, **un seul continent** : le **Panghor** — masse terrestre gigantesque entouree d'un ocean sans nom.

### La Fracture du Panghor

Les 45 Etheres, en s'installant chacun dans leur zone, creent des tensions geologiques. **Flamara** entre en resonance avec **Terranu**. Le Panghor commence a se fissurer sur des centaines de milliers d'annees.

**Fracture 1 — Le Grand Schisme**
- Le Panghor se separe en 2 masses : **Panghor Nord** et **Panghor Sud**
- L'**Ocean Primordial** les separe
- Mont Originel reste au Sud, Mont Jumeau au Nord

**Fracture 2 — L'Eclatement**
- Panghor Nord → 5 masses : futurs Alkaran, Celethor, Galenor, Ilthara, Cestra
- Panghor Sud → 4 masses : futurs Onara, Endora, Azoria, bloc Cendara+Evertia
- 3 fragments isoles entre les deux : futurs Baelor, Nysaria, Ulinor

**Fracture 3 — Les Details**
- Cendara se separe d'Evertia (eruptions volcaniques brisent le pont terrestre)
- Cestra s'eloigne vers le nord, s'isole dans les glaces
- Les iles de l'Archipel d'Azoria se fragmentent

**Implications pour le lore :**
- Les ruines les plus anciennes de la carte = vestiges de l'epoque du Panghor
- Deux nations separees par un ocean peuvent avoir des ruines identiques
- Le fond de certains oceans cache des routes terrestres englouties, cites noyees

## ERE II — L'EVEIL DES MORTELS (~45 000 → ~20 000 av.A)

> **Fichier detaille :** [Chronologie_Era2.md](Chronologie_Era2.md)

### Les premieres ames (~45 000 av.A)

**Spiritus** ne "cree" pas les mortels. Les premiers mortels apparaissent spontanement — parce que Spiritus + Somnix + Judicar existent tous les trois. La conscience emerge quand le souffle, le reve et le sens moral se combinent.

Premiers mortels : proto-peuples primitifs, nomades, groupes de 20-50. Pas de construction permanente.

### Les Cinq Berceaux

5 zones produisent les premieres populations :

| Berceau | Region | Peuple | Trait |
|---------|--------|--------|-------|
| Flamme | futur Cendara/Onara | Marcheurs de Cendre | Premiers forgerons primitifs, peaux sombres |
| Pierre | futur Alkaran | Enfants de la Roche | Robustes, trapus, premiers a creuser la roche |
| Vent | futur Galenor | Coureurs | Agiles, nomades rapides, premiers cavaliers |
| Brume | futur Celethor/Ilthara | Voix-sous-Bois | Discrets, perceptifs, premier langage complexe |
| Eau | futur Azoria/iles | Gens de l'Eau | Nageurs, navigateurs, premiers a traverser l'eau |

Chaque Berceau produit des lignees culturelles distinctes (pas des races fantastiques — des cultures profondes).

### Les Proto-Civilisations (~40 000 → ~30 000 av.A)

Les groupes grossissent lentement :
- **Enfants de la Roche** : premiers abris permanents (cavernes amenagees)
- **Marcheurs de Cendre** : poterie, cuisson du metal brut, premieres forges primitives
- **Coureurs** : domestication des premieres montures, distances immenses
- **Voix-sous-Bois** : tradition orale extraordinairement complexe, recits millenaires
- **Gens de l'Eau** : premiers radeaux, premieres pirogues

Les 5 proto-civilisations ne se connaissent pas. Separees par oceans, montagnes, deserts. Chacune croit etre seule au monde.

### LE GRAND GEL — 1ere quasi-extinction (~30 000 av.A)

**Climata** entre dans un cycle long de refroidissement — pas par malveillance, rythme naturel.

**Ce qui se passe :**
- Temperatures chutent brutalement sur 200 ans
- Glaciers couvrent nord d'Alkaran, tout Cestra, nord de Celethor
- Oceans refroidissent — Gens de l'Eau perdent leurs sources de nourriture
- Forets du Berceau de Brume meurent a 70%
- Seuls epargnes : Marcheurs de Cendre (feu volcanique protege)

**Bilan : ~80% de la population mortelle disparait**
- Enfants de la Roche : survivent dans cavernes profondes, reduits a quelques centaines
- Coureurs : refugies au sud de Galenor, groupes minuscules
- Voix-sous-Bois : perdent quasi-totalite de leur tradition orale — millenaires de memoire effaces
- Gens de l'Eau : disperses sur les iles restantes, isoles
- Marcheurs de Cendre : deviennent le groupe dominant par simple survie

**Traces dans le monde actuel :**
- Cavernes profondes d'Alkaran : **peintures rupestres** d'avant le Gel (plus anciennes traces)
- Ruines de Nysaria : peut-etre vestiges d'un peuple du Gel isole pour survivre
- Cestra jamais recolonisee — la Chose sous le Glacier est peut-etre un vestige du Gel

**Le Grand Gel dure ~5 000 ans** (~30 000 → ~25 000 av.A)

### La Reconstruction (~25 000 → ~20 000 av.A)

Le monde se rechauffe. Les survivants sortent.
- Proto-civilisations d'avant le Gel sont brisees
- Groupes survivants se melangent, fusionnent, s'absorbent
- De nouvelles cultures emergent du melange — plus les "purs" Berceaux
- Premiers echanges entre continents grace aux ponts de glace fondants (passages temporaires)

## ERE III — L'AGE DU LIEN (~20 000 → An 0)

> **Fichier detaille :** [Chronologie_Era3.md](Chronologie_Era3.md)

### La Decouverte du Lien (~20 000 av.A)

Trois individus decouvrent le Lien independamment, a quelques decennies d'intervalle :
- **Orvane la Tisseuse** (futur Celethor, ~20 050 av.A) — medite dans une clairiere, contact avec Arborius

Le Lien se repand sur ~1 000 ans. Chaque mortel doit trouver sa propre resonance.

- **~3 000 → ~1 000 av.A** : fusions, conquetes, alliances — les royaumes se fondent en empires regionaux
- **~1 000 → An 0** : 6 grands empires dominent le monde, age d'or tardif (~120 millions d'habitants, 7 cites volantes, 200 portails)

### Le Premier Delie — Graines de la Chute (~1 100 av.A → An 0)

La chute du Lien est le fruit de deux hommes separes par un millenaire :

**Verithan, le Philosophe (~1 100 → ~500 av.A)**
- Ne en Endora d'un pere et d'une mere Lies — mais lui-meme non-Lie (incapable d'acceder au Lien)
- Etudie le Lien a l'Academie de Lumasar (Galenor) vers ~1 080 av.A
- Ecrit le **Traite du Vide** (~1 000 av.A) : les mortels dependent du Lien comme des esclaves de leur maitre. Un jour, quelqu'un tirera sur le fil — et tout se dechirera
- Fonde les **Verithani**, ordre philosophique clandestin qui perpetue ses ecrits
- Meurt vers ~500 av.A apres ~600 ans de vie (longevite inexpliquee, objet de theologies)
- Ses disciples, les Verithani, cherchent pendant des siecles comment accomplir ce qu'il a predit

**L'Etudiant, l'Executant (~120 av.A → An 0)**
- Nom reel perdu ; ne a Galenor, Lie de puissance moderee
- Herite des textes des Verithani, les prend pour ce qu'ils sont : un plan possible
- Etudie a l'Academie d'Aethranor, decouvre le concept de **Noeud** (point de connexion sectionnable de l'ame)
- **~60 av.A** : Banni de l'Academie quand ses recherches sont decouvertes
- **~30 av.A** : Forme le Cercle des Huit — 8 disciples de differentes nations, heritiers des Verithani
- **An 0** : Accomplit le rituel au **Mont Cendra** (Premier Ancrage du monde — la Trame y est la plus dense). Se coupe volontairement du Lien. La vibration se propage a toute la Trame.

## ERE IV — L'ARRACHEMENT (An 0)

> **Fichier detaille :** [Chronologie_Era4_5.md](Chronologie_Era4_5.md)

### L'Evenement

L'Etudiant accomplit le rituel au sommet du **Mont Cendra** — Premier Ancrage physique du monde, lieu de Flamara depuis la Genese, endroit ou le Lien est le plus concentre. Symmbolisme voulu : la creation et la rupture au meme point.

Il sectionne son propre Noeud. La vibration se propage a toute la Trame cosmique en **7 heures**, rayonnant depuis le Mont Cendra.

**Heure par heure :**
- H1 : Cendara + Onara — berceau de l'Arrachement, devastation totale. Mont Cendra entre en eruption
- H2-3 : Alkaran + Ilthara + Endora — empires s'effondrent en temps reel
- H4-5 : Galenor + Celethor + Nysaria — reseau de portails coupe, cites volantes tombent
- H6-7 : Azoria + Baelor + Ulinor + Evertia + Cestra — Navoria commence a couler, derniers continents touches

**Effets sur les Eternels :**
- **Navigor** : disparait. Les chemins entre dimensions se ferment. Les ames des morts n'ont plus de guide.
- **Eldoria** : sombre dans le Grand Sommeil. Plus aucune nouvelle etoile ne naitra.
- **Tempora** : blesse. Les Failles du Temps apparaissent (zones ou passe/present/futur se melangent).
- **Celestia et Noctis** : desequilibres. Les cycles jour/nuit deviennent erratiques pendant des siecles.

**Bilan de l'Arrachement :**
- Population mondiale : ~120 millions → ~30 millions en un an (famine, effondrements, guerres)
- Cites volantes : detruites (Althanar, Pyranel, Lithanel Haute...)
- Portails : tous fermes (reseau de 200+ portails coupe)
- Navoria : engloutie sous les flots en 3 jours
- Le Lien : rompu pour la vaste majorite des mortels

## ERE V — LA GRANDE NUIT (An 0 → ~3 000 ap.A)

> **Fichier detaille :** [Chronologie_Era4_5.md](Chronologie_Era4_5.md)

### Les Premieres Decennies (An 0 → ~200 ap.A)

Chaos total. Les survivants ne comprennent pas ce qui s'est passe. Les empires sont des cadavres.

- Famine mondiale : les champs magiques ne poussent plus, les guerisseurs sont morts
- Guerres de predation : les plus forts pillent les plus faibles
- Epidemies : sans guerisseurs du Lien, des maladies banales deviennent mortelles
- Les Eternels silencieux : pour la premiere fois, les prieres ne recoivent pas de reponse

### Le Fleau Silencieux (~1 500 ap.A) — 3e quasi-extinction

Une epidemie mystique liee aux residus du Lien brise se repand. Les personnes ayant encore une connexion faible au Lien developpent des symptomes : saignements des yeux, paralysie, puis mort.

**Bilan : ~40% de la population de l'Ere V elimine.**

Survivants privilegies : les non-Lies et les populations peu dependantes du Lien (Baelor, Ulinor, certaines iles d'Azoria).

### Les Royaumes Intermediaires (~500 → ~3 000 ap.A)

De petits royaumes emergent des cendres. Des clans, des cites-etats, des theocracies locales. Ces royaumes seront les briques de l'Ere des Nations.
