# Vautours avec honneur

## Description

Livre rituel des **chasseurs nécromanciens** d'Ilthara. Permet d'invoquer 5 vautours-éclaireurs qui suivent le lecteur 10 minutes — révèlent les ennemis cachés dans 50m. Une fois consumé, les vautours emportent le livre dans le ciel.

## Stats

Invoque 5 vautours-éclaireurs 10 min · Détection ennemis 50m · Single-use
