# Élixir cosmique d'Aetheron

## Description

Liquide doré intense, presque solide tant il est dense. Préparé pendant le **Rêve Lumineux** d'une Ère, dans un autel d'Eldoria. Le buveur entend brièvement la voix d'Aetheron. **Instable** : se conserve 7 jours réels max.

## Stats

+1200 HP instantané + 30% HP max temporaire 60s · OU +100 HP/s × 20s = 2000 régen · 0.8s à boire · 25% chance d'effet secondaire (voir L'Accord) · Conservation 7 jours instable
