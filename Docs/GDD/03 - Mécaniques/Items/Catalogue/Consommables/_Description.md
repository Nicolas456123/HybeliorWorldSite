# Consommables — Branche racine

> Items à usage unique ou limité, déclenchent un effet quand consommés. 11 sous-types canoniques. Cooldown global potion : 30s même catégorie de ressource. Voir [[../../_Templates/Potion|template Potion]] et [[../../_Templates/Pain|template Pain]].

## Sous-branches

| Sous-branche | Effet principal | Pattern |
|--------------|-----------------|---------|
| [[Potions/_Description\|Potions]] | Soin / Mana / Stamina / Antidote / Buff | Burst + cooldown 30s |
| [[Pains/_Description\|Pains]] | Stamina + buff stat (durée) | Hors-combat, action lente 3-5s |
| [[Boissons/_Description\|Boissons]] | Buff stat / résistance (durée) | Hors-combat |
| [[Parchemins/_Description\|Parchemins]] | Sort encapsulé (single-use) | Cooldown propre |
| [[Livres-Récipient/_Description\|Livres-Récipient]] | Sort encapsulé multi-charges | Pont avec Tome |
| [[Aliments bruts/_Description\|Aliments bruts]] | Stamina léger | Frais, conservation 1-3j |
| [[Champignons/_Description\|Champignons]] | Nourriture / alchimique | Variant alchimique |
| [[Gâteaux/_Description\|Gâteaux]] | Stamina + Présence | Festif |
| [[Modificateurs/_Description\|Épices/Herbes]] | Modificateur recette | Pas consommé direct |
| [[Cristaux usables/_Description\|Cristaux usables]] | Recharge Mana / rituel | Single-use rituel |
| [[Récipients/_Description\|Récipients]] | Contenant vide/plein | Vide=équipement, plein=consommable |
