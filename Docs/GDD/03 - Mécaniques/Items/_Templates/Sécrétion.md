# 🧪 Sécrétion — Archétype ressource créature

> Substance produite par **glande spécialisée** : glande à musc (parfumerie), glande répulsive (poison alarme), glande attractive (attirance pour piège), glande médicinale (soin), glande énergétique (résidu cosmique). Distincte de [[Bave]] (visqueuse non-toxique muqueuse) et [[Venin]] (toxique offensif). Composant **multi-fonction** spécialisé selon glande.
>
> Voir [[Sources de Ressources]] §Récolte créature · [[Crafts]] §Alchimie · [[Bave]] · [[Venin]]

---

## 1. Vue d'ensemble

La **Sécrétion** est un fluide **glandulaire ciblé** — chaque glande a sa fonction physiologique précise, qui se traduit en effet alchimique :

| Glande | Sécrétion produite | Usage canonique |
|--------|---------------------|-----------------|
| **Glande à musc** | Musc | Parfum, signature olfactive, dressage |
| **Glande répulsive** | Sécrétion répulsive | Poison alarme, repousse créatures, piège |
| **Glande attractive** | Phéromone | Attractif pour piège ou dressage |
| **Glande médicinale** | Baume glandulaire | Soin physique mineur, panacée locale |
| **Glande énergétique** | Résidu cristallisable | Composant alchimie cosmique (élémentaires) |
| **Glande venimeuse** | (voir [[Venin]]) | — |

**Pas de Sécrétion utile** chez les créatures sans glande développée (poissons standard, certains aviens).

## 2. Variations / origines créatures

### Mammifères (musc, glandes anales)
- [[Loup forestier]] : Glandes anales (musc fort, dressage) ; glandes médicinales (T2)
- [[Ours brun]] : Bile de l'ours (sous-tag *Sécrétion* possible — composant médical Skaldoria)

### Insectoïdes
- [[Ruche d'insectes]] : Phéromone d'attraction (T3, attractif piège), Sécrétion répulsive de soldat (T3)

### Aquatiques
- [[Krill géant]] : Sécrétion abyssale (T3-T4)
- *Calmar géant* (à créer) : Encre noire (sous-type Sécrétion)

### Slimes
- [[Slime amorphe]] : Sécrétion de slime (T2-T3, généralement classée *Bave*, mais glande énergétique = Sécrétion)

### Cosmiques
- [[Élémentaire de feu]] : **Résidu de noyau** (T4-T5, alchimie de feu)
- [[Spectre des Ères]] : Sécrétion temporelle (T5)
- [[Tentacule abyssal]] : Sécrétion abyssale (T5-T6)

### Démoniaque
- [[Démon mineur]] : Glande corrompue (T4, alchimie Voie de Noctis)

## 4. Drop / Récolte

| Critère | Détail |
|---------|--------|
| **Métier** | Dépéceur (sous-Maîtrise *Récolte glandulaire*) |
| **Palier minimum** | Initié (T2-T3), Adepte (T4), Expert (T5+), Maître (T6) |
| **Outil requis** | Pince glandulaire fine + Fiole hermétique |
| **Drop rate** | 30-50 % par glande spécifique (créature peut avoir 2-4 glandes différentes) |
| **Mini-jeu** | Inciser autour de la glande sans la rompre ; un dérapage contamine (T-1) ou perd (T-2) |
| **Modificateur** | × 1.5 vétéran ; × 2 cosmique ; **timing crucial** (<2 h après mort) |

> **Récolte vivante** : Compagnon (Phase 4) peut "donner" sa glande (musc) régulièrement — bonus karma.
