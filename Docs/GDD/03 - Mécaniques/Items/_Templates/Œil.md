# 👁 Œil — Archétype ressource créature

> Organe de vision prélevé sur créature morte (très rare sur vivante — récolte taboue). **Composant alchimique rare** : la signature optique confère aux potions et focus une **vision augmentée** (vision nocturne, vision thermique, voir à travers les murs, vision du Lien). Le **type d'œil** dicte l'effet.
>
> Voir [[Sources de Ressources]] §Récolte créature · [[Crafts]] §Alchimie · [[Antenne]] (composant sensoriel frère)

---

## 1. Vue d'ensemble

L'**Œil** est un **organe optique** porteur de **mémoire visuelle** dans sa rétine et son nerf optique. Récolté frais (idéalement <2 h après mort), il sert :
1. **Composant alchimique** — *Potion d'Œil de [créature]* confère temporairement le type de vision de la créature
2. **Focus magique** — sertis dans [[Orbe]] ou [[Talisman]] pour Voie d'Aurion (perception)
3. **Bijou rituel** — folklore druidique, oracle de Fatum
4. **Cuisine rare** — œil de poisson, certaines cultures (Astravia)

**Type d'œil** détermine l'effet :
- **Œil de prédateur nocturne** → Vision nocturne
- **Œil avienne** → Vision longue distance (× 4 zoom)
- **Œil de reptile** → Vision thermique
- **Œil de poisson abyssal** → Vision sous-marine pression
- **Œil de spectre / cosmique** → Vision du Lien (voir mana, Voies actives)

## 8. Décisions ouvertes

- **Cuisine éthique** : œil de poisson commun, mais œil de mammifère/humanoïde = taboue. Karma effect.
- **Cristallisation rituelle** : recette Apothicaire palier 4+ pour préservation Magistrale — à formaliser Phase 2.
- **Œil de PNJ humanoïde** : marché noir karma rouge — voir [[PvP]].
- **Drop rate variable** : 1-2 yeux (paire). Faut-il drop unitaire ? **Proposition** : oui, un œil peut être détruit en combat (flèche, dégât facial).
