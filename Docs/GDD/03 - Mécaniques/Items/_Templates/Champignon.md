# 🍄 Archétype — Champignon (Récolte)

> Sous-catégorie de la **catégorie [[Catégories d'Items|Récolte]]**, source [[Sources de Ressources#Source 1 — Récolte nature|Récolte nature]]. Le **champignon brut** récolté avant cuisson/transformation. Distinct de [[Champignons]] (Consommable) qui est la version cuite/utilisable.

---

## 1. Vue d'ensemble

Le **Champignon** récolté est l'item brut sortant du sol — distinct de [[Champignons]] (catégorie Consommable, cuit). Récolté par le [[Métiers|Mycologue]] (spécialiste) ou tout botaniste/cueilleur. **Hybride alimentaire / alchimique** : la moitié des champignons sont comestibles après cuisson, l'autre moitié va exclusivement en alchimie / poison / rituel.

Pattern unique : **identification difficile** (mini-jeu mycologue) — un champignon mal identifié peut être consommé toxique. Plus le palier Mycologue est élevé, mieux le joueur distingue les espèces.

## 4. Spawn / Récolte

| Aspect | Détail |
|--------|--------|
| **Biomes** | Sous-bois forestier (référence), Cavernes humides (cavernicoles), Marécages (espèces toxiques), Caves cultivées (Vytharia) |
| **Outil requis** | Couteau de mycologue · panier d'osier (préserve les spores) |
| **Mini-jeu** | **Identification + coupe** : double mini-jeu — d'abord identifier l'espèce (jauge confiance Mycologue), ensuite couper proprement le pied |
| **Palier de Maîtrise minimum** | Novice (T1-T2) ; Adepte (T3 espèces nobles) ; Expert (T4) ; Maître + condition cachée 🔒 (T5-T6) |
| **Saison favorable** | **Automne** = pic général · Printemps = morilles · Hiver = truffes (limité) · Été = espèces tropicales |
| **Régénération** | Mycélium intact = repousse rapide (3-7 jours) ; arracher au pied = mycélium détruit, plus de respawn |
