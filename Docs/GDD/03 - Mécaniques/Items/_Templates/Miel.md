# 🍯 Archétype — Miel

> Sous-catégorie de la **catégorie [[Catégories d'Items|Récolte]]**, source [[Sources de Ressources#Source 1 — Récolte nature|Récolte nature]]. **Hybride animal-végétal** : produit par les abeilles à partir du nectar des fleurs. Récolté par l'[[Métiers|Apiculteur]] sur ruches naturelles ou cultivées.

---

## 1. Vue d'ensemble

Le **Miel** est l'unique ressource canonique **animal-végétale** d'Hybelior — produit du nectar des fleurs transformé par les abeilles. Récolté en ruches **sauvages** (cueillette risquée — piqûres) ou **cultivées** (Apiculteur, ruche fixe ou mobile).

Triple usage canonique :
- **Cuisine** : édulcorant naturel, pâtisserie, conserves
- **Brasserie** : hydromel (boisson référence), liqueurs
- **Alchimie** : conservation des potions, base de baumes adoucissants

Sous-produit : **Cire d'abeille** (intrant fabriqué — voir [[Sources de Ressources#Source 3]] : Miel + Sève → Cire raffinée).

Marqueur culturel : pays forestiers (Trinoria, Alkaran, Sylthara) en font une fierté.

## 4. Spawn / Récolte

| Aspect | Détail |
|--------|--------|
| **Biomes** | Forêts (ruches sauvages), Plaines fleuries, Jardins, Vergers ; **densité fleurs** détermine production |
| **Outil requis** | **Soufflet à fumée** + couteau d'apiculteur + récipient · combinaison protectrice contre piqûres |
| **Mini-jeu** | **Apaisement abeilles** : utilisation rythmique du soufflet à fumée (jauge "calme ruche") avant prélèvement ; échec = 5-15 piqûres (dégâts mineurs) |
| **Palier de Maîtrise minimum** | Novice (T1-T2 ruche basique) ; Adepte (T3 ruches florales spécifiques) ; Expert (T4) ; Maître (T5) |
| **Saison favorable** | **Été** = pic absolu (floraison maximale) · Printemps = production faible mais qualité haute · Automne = stock de l'année · Hiver = rien |
| **Régénération** | Ruche cultivée : production continue (récolte mensuelle) · Ruche sauvage : 1-2 récoltes/an, abeilles peuvent abandonner si trop pillé |

- **Miel de Lavande de Sylthara** (Ilthara) — référence parfumée, base des hydromels prestige.
- **Miel d'Acacia de Trinoria** (Galenor, Forêt des Mille-Flèches) — léger et clair, produit noble.
- **Miel de Bruyère de Cestra** — foncé et tonique, alchimie d'Endurance des Chamanes des Brumes.

- **Miel d'Aurore de Caëspia** (Evertia) — jardins impériaux, soin amplifié.
- **Miel-de-Phénix de Cendara** — Cendrier, résistance feu, prisé.
