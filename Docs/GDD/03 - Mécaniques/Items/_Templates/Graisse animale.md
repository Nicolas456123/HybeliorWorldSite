# 🟡 Graisse animale — Archétype ressource créature

> Tissu adipeux des mammifères et certains aquatiques (requin, baleine), prélevé en blocs après dépeçage du cuir. **Triple usage canonique** : (a) cuisson (lard, saindoux — base culinaire), (b) lubrification (forge, mécanique), (c) base d'huile (Pressier → Huile fabriquée, voir [[Sources de Ressources]] §Fabrication).
>
> Voir [[Sources de Ressources]] §Récolte créature · [[Crafts]] §Cuisine §Forge · [[Cuir]] (drop frère)

---

## 1. Vue d'ensemble

La **Graisse animale** est le tissu adipeux sous le cuir des mammifères et certains aquatiques. Drop **commun et abondant** (mammifères de biome froid en accumulent beaucoup), peu valorisé unitairement mais volume élevé. Trois transformations clés :

1. **Cuisson** — saindoux (porc/sanglier), gras de bœuf, beurre clarifié → base de toute cuisine maison
2. **Lubrification** — forge (trempe lente), mécanique (charnières), pressier (huile machine)
3. **Base d'huile** (Pressier) — Graisse + Pression → Huile (intermédiaire fabriqué, voir [[Sources de Ressources]] §Fabrication)

**Pas de Graisse chez** : aviens (peu de graisse), reptiles (peu de graisse), élémentaires, slimes, spectres, insectoïdes (cire stockée différemment).

## 2. Variations / origines créatures

### Mammifères terrestres
- [[Loup forestier]] : Graisse modérée (T1-T2), 75 % drop
- [[Ours brun]] : **Graisse abondante** (T2-T3, × 2 alpha) — couche épaisse hibernation
- [[Sanglier]] : Saindoux (T1-T2, base culinaire paysanne)
- [[Cerf majestueux]] : Graisse de cerf (T2)

### Aquatiques
- [[Requin abyssal]] : Graisse de requin (T3, base d'huile combustible)
- *Baleine, cétacé* (à créer) : Graisse cétacée (T4, abondante)

### Reptiles (rare)
- [[Serpent géant]] : Graisse de serpent (T2, alchimie spécialisée)
