# 🟦 Peau — Archétype ressource créature

> Revêtement externe **fin** des mammifères jeunes, des reptiles non-écailleux, des aviens (cuir-peau aviaire) et de toutes les créatures dont la couche externe est trop fragile pour être qualifiée de Cuir. Variante moins durable mais **plus souple** et **plus polyvalente en alchimie** (parchemins, tympans, supports tendus).
>
> Voir [[Sources de Ressources]] §Récolte créature · [[Crafts]] §Travail du cuir · [[Cuir]] (archétype frère)

---

## 1. Vue d'ensemble

La **Peau** est la couche externe **fine** prélevée sur :
- Mammifères **juvéniles** (avant épaississement du cuir)
- **Aviens** (cuir-peau fin sous le plumage — voir [[Plume]] pour le revêtement principal)
- **Reptiles non-écailleux** (anoles, geckos, serpents jeunes)
- **Poissons et truites** (peau + écaille hybride — voir [[Écaille]] pour les écailles dures)

Plus **fragile** que le Cuir (résistance physique réduite), mais **plus souple** : tend mieux, se travaille sans mouillage, sert de support à parchemin, tympan d'instrument, vessie de stockage liquide. **Drop fréquent** sur petits gibier — base de revenus du dépéceur Novice-Initié.

## 2. Variations / origines créatures

### Aviens (cuir-peau)
- [[Aigle royal]] (CR 6) : Peau résistante, sous le plumage dorsal
- [[Faucon]] (CR 3) : Peau fine, support de parchemin léger
- *Petits passereaux* (à créer) : Peau parchemin de scribe

### Mammifères juvéniles
- [[Loup forestier]] juvénile (CR 2) : Peau souple
- [[Cerf majestueux]] juvénile (CR 3) : Peau noble, vêtements raffinés
- [[Sanglier]] juvénile : Peau bas tier
- *Lapins, écureuils, petits rongeurs* (Phase 2) : Peau commune

### Reptiles & Aquatiques
- [[Serpent géant]] juvénile (CR 4) : Peau muée (récolte sans tuer — éthique)
- [[Truite mystique]] (CR 2) : Peau-écaille fine, alchimie aquatique

### Humanoïdes (taboue)
- [[Goblin]] : Peau petite, marché noir

## 4. Drop / Récolte

| Critère | Détail |
|---------|--------|
| **Métier** | Dépéceur (sous-Maîtrise *Dépeçage fin* — palier 2+ pour ne pas déchirer) |
| **Palier minimum** | Novice (T1) ; Initié (T2-T3) ; Adepte (T4 + mues rares) |
| **Outil requis** | Couteau fin (Dépéceur), aiguille de prélèvement (T3+) |
| **Drop rate** | 60 % sur juvéniles, 100 % sur aviens, 80 % sur reptiles non-écailleux |
| **Mini-jeu** | Précision élevée — un dérapage transforme la Peau en chute (perte totale) |
| **Modificateur** | × 0.5 sur créature blessée (peau abîmée par combat) ; **récolte de mue** = +50 % qualité (créature non tuée) |

> **Mue éthique** : récolter sur une mue de serpent / lézard / arthropode permet d'obtenir une Peau **sans tuer** la créature. Bonus karma + qualité +1 tier.

## 8. Décisions ouvertes

- **Quantification Cuir vs Peau** : 70/30 par défaut, mais à valider sur 5-10 créatures représentatives.
- **Mue éthique** : faut-il en faire un système de récolte propre (sans dépéceur) ? **Proposition** : oui, accessible via Maîtrise Botaniste/Cueilleur de mues.
- **Peau humanoïde** : marché noir (karma rouge) — couvert par cette fiche ou archétype distinct ?
- **T5-T6 Peau** : faut-il étendre, ou réserver à Cuir/Écaille ? **Proposition** : pas de T5+ Peau standard ; les variants cosmiques peuvent dépasser, jamais le matériau brut.
- **Peau aviaire vs Plume** : un avienne donne les deux ? **Proposition** : oui, drop séparé (Plume = revêtement principal, Peau = sous-couche).
