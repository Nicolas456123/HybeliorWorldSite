# 🌾 Archétype — Graine

> Sous-catégorie de la **catégorie [[Catégories d'Items|Récolte]]**, source [[Sources de Ressources#Source 1 — Récolte nature|Récolte nature]]. **Multi-usage** : cuisine (épices, condiments, oléagineuses), alchimie (huiles, principes actifs), **plantation** (Fermier, Botaniste).

---

## 1. Vue d'ensemble

La **Graine** est récoltée sur plante mature ou via décortication de fruits/cônes. C'est l'**unité de plantation** d'Hybelior : tout joueur peut, avec assez de graines, démarrer un potager, jardin ou champ. Triple usage canonique :
- **Cuisine** : épices (poivre, moutarde, cumin), oléagineuses (sésame, tournesol, lin)
- **Alchimie** : huiles (intrant fabriqué) — voir [[Sources de Ressources#Source 3 — Fabrication]] : Graine → Huile (Pressier/Apothicaire)
- **Plantation** : démarrage culture par Fermier ; régénération de patch par Botaniste

> Distinction canonique avec [[Céréale]] : Céréale = graine cultivée à grande échelle pour farine ; Graine = tout autre usage.

## 4. Spawn / Récolte

| Aspect | Détail |
|--------|--------|
| **Biomes** | Tous biomes (selon plante-mère). Plaines (Tournesol, Lin), Forêts (Châtaigne, Noix), Tropical (Poivre), Désert (Cumin), Jardins (Sésame, Pavot) |
| **Outil requis** | Tamis, panier · serpe pour têtes de graines (tournesol) |
| **Mini-jeu** | **Tri** : séparer graines pleines des vides via tamisage (jauge précision) ; en sur-tamisant, perte d'unités |
| **Palier de Maîtrise minimum** | Novice (T1-T2) ; Initié (T3) ; Expert (T4) ; Maître (T5) |
| **Saison favorable** | **Fin d'été / Automne** = pic de récolte (graines mûres) · Printemps = quasi-zéro |
| **Régénération** | Cueillette n'affecte pas la plante (graines = produit de reproduction) ; auto-régénération annuelle |

## 7. Signatures notables

- **Poivre Noir de Warenthor** (Ilthara, jungle) — référence épice continentale, échange commercial majeur.
- **Lin de Sylthara** (Ilthara) — huile alimentaire et fibre textile (Lin = double-récolte).
- **Tournesol de Sylthara / Galenor** — huile la plus courante d'Hybelior.
- **Cumin d'Endora** (désert) — épice des nomades de Lythar.
- **Châtaigne des Forêts de Trinoria** (Galenor) — cuisine d'hiver, conservation longue.
- **Graine de Mandragore de Vytharia** — plantation rituelle, donne Mandragore après 1 cycle (rare et précieuse).
- **Graine Cosmique** (variant Verdoiement) — donne plante de l'ère active après plantation.
