# ❄️ Orc-blanc Skaldoria

> Variant Frost du [[Orc]] — **guerrier honoré** par les chefs Skaldoria. Frontière PNJ : ces orcs sont parfois **alliés** contre une menace plus grande.

## Description condensée

Orc standard mais **peau gris-bleu**, fourrure blanche sur les épaules, **canines plus longues**. Armes plus rituelles (hache à motifs gravés). Voix plus grave.

## Comportement

- **Sapient** + **honneur martial** strict
- **Pacte avec chefs Skaldoria** possible (alliance contre menace partagée)
- **Hostile** si offense d'honneur ; sinon coopératif

## Stats de combat

| Variante | CR | HP |
|----------|----|----|
| Orc-blanc | 8 | 380 |
| Orc-blanc champion | 12 | 540 |

**Attaques** : pattern Orc + **Souffle givrant** (cône Froid 3 m), **Charge de neige** (14 m sprint, knockback).

## Loot

- **Cuir lourd polaire** : armure médium isolante
- **Hache rituelle** : composant Magistral (lame avec gravures)
- Maîtrise Dépeçage : Adepte

## Lore régional

- *Skaldoria* → guerriers honorés, parfois alliés
- Frontière PNJ : un chef Orc-blanc dialogable peut devenir PNJ (alliance Phase 4)
