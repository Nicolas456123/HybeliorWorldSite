# 🐍 Serpentidés

> Reptiles allongés, prédateurs d'embuscade. Pose le pattern **infrarouge / venin / constriction / patience d'embuscade**. Hérité de [[_Templates/Serpent géant]].

## Caractères communs

- Forme allongée (3-15 m selon espèce/âge)
- Écailles uniformes, mue annuelle
- **Vision diurne moyenne, infrarouge canonique, audition par vibrations**
- **Instinctif** (BT simple)
- Solitaire, territorialité fixe
- Méthode : **Embuscade pure** + Constriction OU Morsure venimeuse selon variant

## Biomes typiques

Forêt, marais, caverne, plaine boisée, jungle, certains déserts.

## Espèces

- [[Serpent géant des forêts]] — espèce-souche
- [[Vipère des marais d'Ilthara]] — variant Pyrtara venimeux
- [[Sparutor]] — signature CSV (Serpent-Roi des marais Pyrtara)

## Frontières

- **vs Tortues** : pas de carapace + reptation + venin → Serpentidés
- **vs Sauriens** : pas de pattes (rampement pur) + petite/moyenne taille → Serpentidés
