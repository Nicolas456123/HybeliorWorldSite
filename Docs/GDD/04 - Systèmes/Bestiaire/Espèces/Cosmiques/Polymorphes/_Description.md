# 🦎 Polymorphes

> Êtres capables de transformation morphologique. Deux pattern canoniques distincts :
> - **Métamorphes** (prédateurs Apprenants) — chassent par confiance gagnée
> - **Esprits changeformes** (gardiens Sapients) — adoptent la forme attendue par l'observateur

Hérités de [[_Templates/Métamorphe]] et [[_Templates/Esprit changeforme]].
