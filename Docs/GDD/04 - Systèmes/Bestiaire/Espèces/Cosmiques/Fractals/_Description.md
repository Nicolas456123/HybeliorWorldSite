# 💎 Fractals

> Êtres à **géométrie évolutive** — la forme physique se complexifie avec la taille (auto-similarité à toutes échelles). Deux pattern canoniques :
> - **Cristal vivant** : sédentaire, Hivemind émergent, Aetheron + Terre, **filtre énergétique**
> - **Tisseur du Vide** : mobile, Sapient, Vortex + Vide, **mathématicien hostile**

Hérités de [[_Templates/Cristal vivant]] et [[_Templates/Tisseur du Vide]].

## Espèces

- [[Cristal vivant]] — Cathédrale magique sédentaire
- [[Tisseur du Vide]] — boss Avatar hostile mobile
