# 💧 Élémentaire d'eau

> *Stub — espèce parallèle à [[Élémentaire de feu — Cœur d'Eldoria]] avec élément Eau.*

## Pattern canonique

Reprend le pattern Multi-stades + Noyau exposé + Régénération conditionnelle de [[_Templates/Élémentaire de feu]] §10 (table de réutilisation). Substitutions :
- **Aura brûlante** → **Aura humide** (DOT eau, ralentit joueur 20%)
- **Régénération thermique** → **Régénération en zone humide** (sources, pluie)
- **Vulnérabilité** : Feu, Voie d'Eldoria
- **Loot** : Essence spirituelle, **Cœur d'Onde** (intrant alchimie aquatique haute), Cristaux d'eau, **Larme glacée** (rare)
- **Explosion à la mort** → **Dispersion** (vague d'eau projetée, knockback)

## Apparition

- Sources de la Voie d'Aquor (rituels)
- Tempêtes côtières
- Failles aquatiques
- Ère de l'Aquatique Profond (proposition canonique)

Voir [[_Templates/Élémentaire de feu]] §10 chantier de profondeur. Production complète Phase 2 ultérieure.
