# 👹 Démons

> Bipèdes humanoïdes-déformés des Plans infernaux. **Sapient + élément Feu + tentation morale**. Hérité de [[_Templates/Démon mineur]]. Pattern canonique du **dialogue piégé** et du **Pacte démoniaque** (volonté hostile, contrairement aux Élémentaires neutres).

## Espèces

- [[Démon mineur]] — espèce-souche
- [[Démon de cendre]] — variant Brulé Cendara (serviteur du Cœur de Cendra)
- [[Démon-marais d'Ilthara]] — variant pacté avec sorciers Spectres-Pères
- [[Démon industriel de Mosrack]] — variant Pourpre, pacte de richesse
