# 🦅 Faucons

> Petits prédateurs aériens rapides — **les plus rapides du bestiaire** (piqué jusqu'à 90 m/s). Solitaire, **apprivoisables** (fauconnerie canonique). Hérité de [[_Templates/Faucon]].

## Espèces

- [[Faucon pèlerin]] — espèce-souche
- [[Fallilla]] — signature CSV (variant Galenor / Trinoria)
- [[Faucon des sables]] — variant désertique Endora/Mosrack
