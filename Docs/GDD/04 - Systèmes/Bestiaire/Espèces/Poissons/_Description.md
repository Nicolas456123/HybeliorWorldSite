# 🐟 Poissons

> Vertébrés aquatiques. Hybelior distingue **Eaux douces** (école de Pêche, ressources alimentaires) et **Abysses** (apex marin, combat aquatique). Hérité de [[_Templates/Truite mystique]] et [[_Templates/Requin abyssal]].

## Caractères communs

- Forme allongée hydrodynamique
- Revêtement Écaille (et Cuir denticulé pour Abysses)
- Sens : Vision aquatique, électroception, audition aquatique, **odorat du sang** (Abysses)
- Ovipare (poissons d'eau douce) ou Vivipare (Requins abyssaux)
- **Ressource récurrente non-combat** (Eaux douces) ou **boss aquatique** (Abysses)

## Sous-familles

- [[Poissons/Eaux douces/_Description|Eaux douces]] — pêche, ressources
- [[Poissons/Abysses/_Description|Abysses]] — apex marin

## Frontières

- **vs Reptiles aquatiques** (serpents-marais, tortues) : pas d'écailles complètes mais Cuir/Carapace → Reptiles
- **vs Cosmiques** (Tentacule abyssal) : tentaculaire + Vide → Cosmiques
