# 🐝 Insectes

> Insectoïdes Hivemind — colonies/ruches/swarms à BT collectif partagé. Pattern unique : **multi-rôles** (ouvrière/soldat/reine), **rencontre de groupe massive** (50-200 individus). Hérité de [[_Templates/Ruche d'insectes]].

## Espèces

- [[Ruche d'abeilles géantes]] — pollinisatrices industrielles, miel + cire
- [[Fourmilière colossale]] — fourmis de guerre, élevage de pucerons-géants
- [[Termites souterrains du Mosrack]] — variant industriel, exploitation Mosrack
- [[Swarm de scarabées de cendre]] — variant Brulé Cendara
