# 🦅 Aigles

> Grands prédateurs aériens, Couple à vie, territoire fixe immense (50-200 km²). Pose le pattern **chasse coordonnée en couple** (BT partagé). Hérité de [[_Templates/Aigle royal]].

- [[Feopsingale]] — signature CSV (Aigle royal de Galenor — Cimes de Veltora)
