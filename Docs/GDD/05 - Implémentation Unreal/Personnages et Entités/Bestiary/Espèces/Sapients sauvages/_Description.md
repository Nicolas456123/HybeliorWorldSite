# 👹 Sapients sauvages

> Créatures **Sapientes natives** non-cosmiques (intelligence comparable humaine, langage, outils). Frontière directe avec [[PNJ]] : un Sapient sauvage **dialogable / clan amical** sort du Bestiaire et devient PNJ.

## Convention canonique frontière

- **Sapient sauvage** (clan hostile par défaut, agressif sans dialogue, prédateur/charognard) → **Bestiaire** (cette catégorie)
- **Sapient domestiqué / clan amical / pacté** (dialogue complet, MBTI, quêtes) → **[[PNJ]]**
- **Promotion narrative** : un même individu peut **basculer** par dialogue résolu — pattern canonique posé dans [[_Templates/Goblin]] §10

## Caractères communs

- Bipèdes Petits à Grands
- Revêtement **Cuir + Tissu + Métal pillé** (artificiel — habillement, armures pillées)
- Sapient natif (intelligence 60-110 humain selon espèce)
- **Loot artificiel** signature : Outils, Pièces, Armes, Trophée crâne — **différent du loot biologique**

## Sous-familles

- [[Sapients sauvages/Goblinoïdes/_Description|Goblinoïdes]] — Goblin (Petit, charognard) + Orc (Grand, guerrier)
- [[Sapients sauvages/Autres/_Description|Autres]] — Vermifuge des sables (Tentaculaire biologique non-cosmique, placé ici par convention par défaut — frontière à raffiner)

## Frontières

- **vs Mammifères** : Sapient + bipède + outils → Sapients sauvages
- **vs Cosmiques** : biologie indigène → reste Sapients sauvages
- **vs PNJ** : individu/clan dialogable → PNJ (promotion narrative)
