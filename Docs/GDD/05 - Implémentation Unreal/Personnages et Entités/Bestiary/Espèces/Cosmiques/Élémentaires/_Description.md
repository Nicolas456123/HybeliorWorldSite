# 🔥 Élémentaires

> Manifestations énergétiques planaires liées aux Voies/Éléments. **Multi-stades par croissance** (Étincelle → Petit → Standard → Grand → Avatar). Pattern canonique : **Aura passive + Projection + AoE éruption + Noyau exposé** (point faible canonique). Hérité de [[_Templates/Élémentaire de feu]].

## Frontières

- **vs Démons** : pas de volonté hostile par défaut — neutre énergétique → Élémentaires
- **vs Spectres** : matériel (plasma magique) — pas incorporel → Élémentaires
- **vs Fractals** : amorphe (pas de structure géométrique stable) → Élémentaires
