# 🌌 Cosmiques

> Êtres planaires sans biologie indigène à Hybelior. Manifestations des Voies, des Ères, du Vide. Tous regroupés ici par opposition aux espèces biologiques (Mammifères, Reptiles, etc.). Le sous-groupement reflète **l'axe morphologique** dominant.

## Caractères communs

- **Pas indigène matériel** : viennent des Voies, Plans, Ères
- **Pas de cycle biologique** au sens classique (Bourgeonnement, Spores, Multi-stades cosmiques)
- **Durée de vie Immortelle** ou Éphémère selon nature
- **Loot magique uniquement** : Essence spirituelle, Cristaux fondus, Larme, Sécrétion, Cœur (cristallin/de flamme/de glace)
- **Pas de Cuir, Os classiques, Fourrure, Plume** (sauf rares exceptions selon morphologie)
- **Pattern d'apparition événementielle** (pas faune errante)

## Sous-familles

- [[Cosmiques/Élémentaires/_Description|Élémentaires]] — masses énergétiques (Feu, Eau, Terre, Air, etc.)
- [[Cosmiques/Spectres/_Description|Spectres]] — incorporels temporels (Tempora)
- [[Cosmiques/Démons/_Description|Démons]] — bipèdes infernaux (Plan infernal)
- [[Cosmiques/Polymorphes/_Description|Polymorphes]] — formes mutables (Métamorphes prédateurs, Esprits gardiens)
- [[Cosmiques/Fractals/_Description|Fractals]] — géométrie évolutive (Cristal vivant Aetheron, Tisseur du Vide)
- [[Cosmiques/Tentaculaires/_Description|Tentaculaires]] — avatars colossaux du Vide (Tentacule abyssal)

## Frontières

- **vs Espèces biologiques** : pas de biologie indigène → Cosmiques
- **vs Spectres / Démons** : Spectre = Sapient + Tempora ; Démon = Sapient + Infernal + tentation morale
- **vs Tentaculaires biologiques** : [[Vermifuge des sables]] est Tentaculaire mais **biologique** (placé en Sapients sauvages/Autres) — pas Cosmique. Pattern canonique : Tentaculaire ≠ forcément Cosmique.
