# 🐙 Tentaculaires (cosmiques)

> Avatars cosmiques tentaculaires colossaux du Vide. **Avatars** par défaut — boss continentaux. Hérités de [[_Templates/Tentacule abyssal]].

> ⚠️ **Frontière taxonomique** : un être Tentaculaire **n'est pas forcément cosmique**. Le [[Vermifuge des sables]] est Tentaculaire mais **biologique** (placé en [[Sapients sauvages/Autres/_Description|Autres]]). Pattern canonique posé dans [[_Templates/Vermifuge des sables]] §2.

## Espèces

- [[Tentacule abyssal]] — espèce-souche (Avatar océanique)
- [[Tentacule abyssal — Le Long-Bras des Marais]] — variant Pourpre Pyrtara (Ilthara)
- [[Bouche du Cendre]] — variant Brulé Cendara (avatar volcanique sous-marin)
