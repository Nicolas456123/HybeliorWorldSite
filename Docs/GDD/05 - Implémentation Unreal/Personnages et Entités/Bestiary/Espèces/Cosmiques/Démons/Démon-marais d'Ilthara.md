# 👹 Démon-marais d'Ilthara

> Variant pacté avec les sorciers Spectres-Pères de Pyrtara. Pattern Démon mineur + brume venimeuse marais. **Souvent invoqué** par sorciers ; jamais natif.

## 1. Description physique

Bipède (1.8-2.2 m). Peau **noire-violacée**, cornes courbes courtes, doigts palmés (adaptation marais), brume verdâtre-violacée environnante.

## 2-5. Cycle / Comportement

- Pattern Démon mineur + immunité Eau + résistance Poison + Confusion (Pourpre)

## 6. Stats de combat

| Variante | CR | HP |
|----------|----|----|
| Démon-marais | 12 | 380 |

**Attaques** : pattern Démon mineur + **Souffle vénimeux** (cône 5 m, Poison + Confusion).

## 7. Loot & exploitation

- **Cuir noir putride** : armure résistance poison
- **Sécrétion sulfureuse** : alchimie de poison

## 8. Lore régional

- *Pyrtara (Ilthara)* → invoqué par sorciers Spectres-Pères pour pactes
- Lore moralement ambigu (les sorciers Pyrtariens utilisent les démons sans être considérés "mauvais")
