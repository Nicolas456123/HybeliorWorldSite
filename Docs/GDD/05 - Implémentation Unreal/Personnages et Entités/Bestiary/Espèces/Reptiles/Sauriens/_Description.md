# 🐉 Sauriens

> Reptiles évolués massifs — **dragons et créatures dragoniques** d'Hybelior. Hérité de [[_Templates/Dragon nain]]. Apex absolu de leur territoire, **Sapients** par défaut, **dialogables** dans le draconique ancien.

## Caractères communs

- Quadrupèdes Colosses ailés (8-15 m chez le Nain, plus pour Majeur/Ancien)
- Revêtement Écaille épaisse + Cristaux mineurs (cornes, gemmes)
- **Sapient** (intelligence supérieure 110-140 humain, mémoire vive)
- **Solitaire** absolu, territorialité fixe (antre)
- **Souffle élémentaire** (variable selon clan : Feu, Eau, Terre, Air, Glace, Foudre)
- **Évolution avec l'âge** : Nain → Majeur → Ancien

## Biomes typiques

Montagne, caverne, pic, volcan dormant, ruines profondes. Variantes selon élément.

## Espèces

- [[Dragon nain]] — espèce-souche (toutes affinités élémentaires)
- [[Zocshawk]] — signature CSV (Dragon Nain de Cendara, Cœur = Acier Éternel)

## Frontières

- **vs Tortues** : ailes + Souffle élémentaire + apex → Sauriens
- **vs Cosmiques** : biologie indigène (les dragons sont nés sur Hybelior, pas planaires) → reste Reptiles
- **Dragon ↔ PNJ** : un dragon Sapient lié à un joueur peut être traité côté PNJ pour les arcs narratifs (Pacte Phase 4)
