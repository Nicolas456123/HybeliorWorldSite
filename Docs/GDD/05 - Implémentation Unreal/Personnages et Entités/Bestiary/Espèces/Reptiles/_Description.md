# 🦎 Reptiles

> Vertébrés à écailles, sang froid, ovipares. Hybelior compte trois grandes branches reptiliennes : Serpentidés (rampement, embuscade, venin), Tortues (carapace, longévif, sapient avec l'âge), Sauriens (reptiles évolués massifs incluant les dragons).

## Caractères communs

- **Sang froid** : actifs surtout en climats chauds-tempérés ; hibernation/léthargie en biomes froids
- **Écailles** (revêtement uniforme, mue annuelle ou multi-annuelle)
- **Ovipares** (œufs déposés en lieux secs ou humides selon famille)
- **Infrarouge** (canonique reptile — perçoit chaleur des proies à 30 m)
- **Loot** : Écaille, Os, Crocs, Venin (variable), Œuf, Cœur

## Biomes typiques

Forêt, marais, caverne, plaine boisée, jungle, eau douce, océan profond, montagne (dragons), cendres volcaniques (dragons de feu).

## Frontières

- **vs Mammifères** : sang chaud + fourrure → Mammifères
- **vs Cosmiques** : biologie indigène (même les dragons restent reptiles, pas cosmiques) → Reptiles
- **Dragons sapients ↔ PNJ** : un dragon dialogable de longue date peut être traité côté PNJ pour les arcs narratifs. Pattern partagé avec [[Yéti]].
