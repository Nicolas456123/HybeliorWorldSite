# 🟢 Amorphes

> Êtres **gélatineux semi-vivants** sans squelette ni élément intrinsèque. Pattern complémentaire à [[Cosmiques/Élémentaires/_Description|Élémentaires]] (Amorphe + élément). Hérité de [[_Templates/Slime amorphe]].

## Caractères communs

- Forme Amorphe pure (masse gélatineuse)
- Pas de revêtement (membrane gélatineuse)
- Détritivore primaire — **décomposeur** essentiel des écosystèmes humides
- **Division binaire** à la mort (pattern unique)
- **Absorption passive** (recouvre proie)
- **Tranchant inutile** : pédagogie inverse de mammifère (contondant ou magique)

## Espèces

- [[Slime amorphe]] — espèce-souche
- [[Slime cendreux]] — variant Brulé Cendara
- [[Slime des marais]] — variant Pourpre Pyrtara

## Frontières

- **vs Élémentaires** : pas d'élément intrinsèque + pas de noyau cristallin → Amorphes
- **vs Cosmiques** : biologie indigène (slimes nés sur Hybelior) → Amorphes (pas Cosmiques)
