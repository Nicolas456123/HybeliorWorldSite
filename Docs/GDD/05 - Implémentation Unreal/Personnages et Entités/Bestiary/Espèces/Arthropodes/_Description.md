# 🐝 Arthropodes

> Invertébrés à carapace chitineuse — insectes (Hivemind), crustacés (aquatiques colossaux), arachnides (solitaire désertique). Pose le pattern **Carapace + Antenne + Sécrétion** au lieu de Cuir + Os + Sang du loot mammifère.

## Caractères communs

- Forme Insectoïde principalement (avec composante quadrupède chez crustacés)
- Revêtement **Carapace** chitineuse (mue saisonnière)
- Sens : Vision 360°, Détection vibrations, Détection chimique (phéromones)
- Reproduction par **œufs en grand nombre** (Spores) ou **mue larvaire**
- **Loot** : Carapace, Antenne, Sécrétion, Pince/Dard, Œuf

## Sous-familles

- [[Arthropodes/Insectes/_Description|Insectes]] — ruches Hivemind (abeilles, fourmis, guêpes géantes)
- [[Arthropodes/Crustacés/_Description|Crustacés]] — krills géants, crabes-titans (aquatiques)
- [[Arthropodes/Arachnides/_Description|Arachnides]] — scorpions géants (solitaires désertiques)

## Frontières

- **vs Reptiles** : pas de squelette interne + carapace → Arthropodes
- **vs Cosmiques** : biologie indigène (même les ruches géantes restent biologiques) → Arthropodes
- **vs Tentaculaires** (Vermifuge des sables) : annelé sans pattes → Sapients sauvages/Autres (placement par défaut), mais frontière à raffiner
