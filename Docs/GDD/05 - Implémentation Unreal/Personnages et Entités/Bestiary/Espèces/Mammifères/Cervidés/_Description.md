# 🦌 Cervidés

> Mammifères quadrupèdes herbivores nobles. Cerfs, biches, élans, rennes. **École du chasseur** d'Hybelior — gibier furtif fuyard. Pattern hérité de [[_Templates/Cerf majestueux]] : **proie privilégiée + Détection préventive + Bond élégant**.

## Caractères communs

- Quadrupèdes Moyens à Grands
- Pelage poils + fourrure légère, **bois ramifiés** (mâles, mue annuelle)
- Sens excellents tous azimuts (paranoïa sensorielle de proie)
- Apprenant
- **Fuite prioritaire** ; combat = exception (rut mâle, acculé, défense de faon)
- Variants magiques mineurs (Cerf de Lune Doré, Cerf de Songe Onirique)

## Biomes typiques

Forêt, plaine boisée, montagne basse, toundra (rennes-géants).

## Espèces

- [[Cerf majestueux]] — espèce-souche tempérée
- [[Cerf de Lune]] — variant Doré rare (Eldoria active)
- [[Renne mythique de Celethor]] — variant arctique
- [[Ceapeecu]] — signature CSV (Cerf-Roi à résolution paisible)

## Frontières

- **vs Bovidés** : herbivore strict + fuite + bois saisonniers → Cervidés
- **vs Mammifères Géants** : taille + bipédie → Yéti
