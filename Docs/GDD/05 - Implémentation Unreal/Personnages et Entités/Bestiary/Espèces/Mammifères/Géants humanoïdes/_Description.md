# 🦍 Géants humanoïdes

> Mammifères bipèdes colossaux à cognition tendant Sapient. **Une seule espèce documentée** : le Yéti. Pose le pattern **mammifère bipède + langage primitif émergent + signature par chaîne montagneuse**.

## Caractères communs

- Bipèdes Colosses (5-7 m debout)
- Revêtement Poils + Fourrure très dense
- **Apprenant tendant Sapient** (cognition évolue par lien soutenu avec un joueur — pattern de "réveil cognitif")
- **Solitaire** absolu (un seul individu par massif montagneux)
- Mémoire **longue** (sessions IRL multiples — pattern unique parmi Apprenants)
- **Loot rarissime** (un Yéti = un drop par massif par cycle d'ère)

## Biomes typiques

Montagne haute, toundra, désert de glace, plateaux gelés, cavernes glaciaires.

## Espèces

- [[Yéti]] — l'unique espèce documentée

## Frontières

- **vs Ursidés** : bipédie + intelligence émergente + langage → Géants humanoïdes (Yéti reste mammifère)
- **vs Sapients sauvages** : pas de société, pas d'outils, pas de Sapient natif → reste Mammifère
- **vs Cosmiques** : biologie indigène (mammifère vivant) → reste Mammifère
