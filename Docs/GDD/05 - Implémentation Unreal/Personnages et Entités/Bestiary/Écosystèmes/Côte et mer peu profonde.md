# 🐚 Côte et mer peu profonde — Écosystème

> Écosystème **transition terre-mer**. Couvre les **côtes** de tous les continents littoraux : **Galenor** (Solena oligarchie maritime, Trinoria), **Onara** (Tyndara République marchande), **Ilthara**, **Cendara archipel**, **Skaldoria fjords** (Alkaran), **Evertia côtes**, **Astravia bordures basses**. Plage, estuaires, récifs, baies. **Premier biome maritime** que rencontre le joueur. Domaine des **crustacés**, **mollusques**, **oiseaux marins**, et juvéniles de [[Krill géant]].
>
> Voir [[Bestiaire - Index]] · [[Géographie]] · [[Krill géant]] · [[Eau douce]] · [[Océan abyssal]]

---

## 1. Description géographique & climat

**Localisation principale** :
- **Galenor** : Solena (oligarchie maritime — Âge des Grandes Explorations), côtes de Trinoria, Lumasar.
- **Onara** : Tyndara (République marchande, Ligue des Marchands).
- **Ilthara** : Haldria (navigation astrale), côtes Sylthara.
- **Cendara** : archipel volcanique, plages de cendre, baies thermales.
- **Skaldoria** (Alkaran) : fjords, mer froide, ports.
- **Evertia** : côtes parcimonieusement accessibles (impériales).
- **Solena** : âge d'or maritime (économie majeure).

**Climat** :
- **Tempéré marin** (Galenor, Onara) à **tropical** (Ilthara, Cendara) à **subarctique** (Skaldoria)
- Brises maritimes constantes
- **Marées** importantes (cycles 12h)
- Pluviométrie élevée
- **Tempêtes** maritimes (automne-hiver)
- Brouillards côtiers fréquents

**Particularités** :
- **Récifs coralliens** (Ilthara, Cendara — tropicaux)
- **Bancs de sable** (Galenor)
- **Estuaires** (jonction eau douce-eau salée — biodiversité maximale)
- **Falaises** (Trinoria, Skaldoria — habitats aviens)
- **Mangroves** (Ilthara, Pyrtara côtière)

## 3. Cycle saisonnier

| Saison | Phénomènes biologiques majeurs |
|--------|-------------------------------|
| **Printemps de migrations** | Bancs poissons remontent. Migrations baleines (rare, périphérie). Reproduction massive (algues, crustacés). Oiseaux marins nichent en falaises. |
| **Été de pic** | Productivité maximale. Pêche intense. Tourisme côtier. Algues prolifèrent. **Festivals maritimes** (Solena, Tyndara). |
| **Automne de tempêtes** | Tempêtes commencent. Migrations vers sud (oiseaux). Tortues marines pondent. **Récolte algues d'hiver**. |
| **Hiver de tempêtes** | Tempêtes violentes. Pêche limitée. Phoques à terre (mises bas). Naufrages occasionnels (Solena Âge des Explorations). |

**Événements signatures** :
- **Tempêtes** = danger + opportunité (épaves)
- **Migrations** = saumons, baleines, oiseaux
- **Floraison phytoplancton** = "marées rouges" possibles
- **Échouages** (baleines, méduses) = ressources éphémères

## 4. Cycle ère cosmique

| Ère active | Effet sur l'écosystème Côte |
|-----------|------------------------------|
| **Ère des Vents Bouleversants** | **Tempêtes cataclysmiques**. Naufrages multiples. Migrations spectaculaires. Plumes du Vent abondantes. Religion Via Ventus prospère. |
| **Ère du Sommeil de Glace** | Côtes gelées (Cestra, Skaldoria). Banquise étendue. Phoques prospèrent. Variant **Frost**. |
| **Ère du Verdoiement** | Algues prolifèrent. Récifs coralliens explosent. Variant **Verdoyant**. |
| **Ère de la Brume Mortelle** | Brouillards côtiers permanents. Naufrages invisibles. Variant **Pourpre**. |
| **Ère du Rêve Lumineux** | Eau dorée scintille. Variant **Doré**. Récifs lumineux. |
| **Ère du Feu Endormi** | Sources thermales sous-marines (Cendara) actives. Eau bouillonne. Variant **Brulé**. Cuivre fondu côtier. |
| **Ère des Échos Brisés** | Vagues paradoxales. Bateaux fantômes. Variant **Spectral**. |
| **Ère du Sommeil Onirique** | Mer en songe. Sirènes apparaissent. Variant **Onirique**. |
| **Ère de l'Ombre Longue** | Côtes nocturnes 24h/24. Pieuvres en plein jour. Variant **Shadow**. |
| **Ère des Présages** | Marées en signes. Vagues prophétiques. Variant **Vénérable**. |

> **Modulation forte** : la côte est **l'écosystème le plus impacté par les ères de vent et d'eau**. Solena (oligarchie maritime) suit ces cycles religieusement.

## 7. Équilibres écologiques fragiles

**Pivots critiques** :
1. **Phytoplancton** — base de tout. Eutrophisation (engrais Galenor) = marées rouges, mort cascade.
2. **Récifs coralliens** — habitats. Réchauffement (Feu Endormi) = blanchiment massif.
3. **Estuaires** — pouponnières. Pollution Mosrack en amont = stérilisation côtière.
4. **Tortues marines** — ponte sur plages. Surpêche oeufs = effondrement démographique.
5. **Bancs poissons** — économie + écologie. Surpêche industrielle Solena = effondrement.

**Liens cosmiques** :
- **Aquor** (Cosmique de l'eau) = patron tutélaire.
- **Aerion** (Cosmique du vent) = co-patron côtier.
- **Solena** = nœud humano-cosmique (Âge des Explorations, navigation rituelle).
- **Solena Cosmique adoré** : religion locale dérivée d'Aquor.

## 8. Présence humanoïde & impact

**Activités humaines** :
- **Pêche** : industrie majeure (Solena, Tyndara, Skaldoria).
- **Navigation** : Solena (oligarchie maritime), Haldria (navigation astrale).
- **Salines** : production de sel (Galenor sud).
- **Perliculture** : huîtres (Solena).
- **Algoculture** : Lumasar académies.
- **Construction navale** : Skaldoria, Solena.

**Sanctuaires religieux** :
- **Aquor** — temples côtiers omniprésents.
- **Foedus Animae** — communion avec esprits marins.
- **Solena** : Âge des Explorations comme religion dérivée.

**Conflits** :
- **Solena vs Tyndara** : guerres commerciales maritimes.
- **Pirates** : raids côtiers (Skaldoria fjords, Cendara archipel).
- **Léviathans des Abysses** menacent Azoria sud — possibilité côtière.
- **Surpêche** : tensions traditionnels vs industriels.

**Quêtes typiques** :
- Récupérer une perle rare (huître monstrueuse)
- Affronter un Phoque léopard (apex côtier)
- Naufrage à explorer (Vents Bouleversants)
- Pêche au Krill juvénile (banc colossal)
- Sauver tortues marines des braconniers
- Naviguer en tempête (mission Solena)
- Découvrir une cité engloutie (récifs)
