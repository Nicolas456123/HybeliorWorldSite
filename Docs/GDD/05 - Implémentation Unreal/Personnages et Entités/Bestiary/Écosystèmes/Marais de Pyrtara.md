# 🐊 Marais de Pyrtara — Écosystème

> Écosystème **humide chaud / tempéré**. Couvre **Pyrtara** (Ilthara — dictature militaire, Grande Éruption — adjacence volcanique-marais), les **Marécages de Noyrath** (Ilthara — voile mince entre les mondes, cf. [[Géographie]]), les zones humides d'**Onara sud** (lacs des cosmiques), et les marais oniriques de **Vytharia** (Ilthara — illusionnistes, rêve/réalité). Domaine du **[[Serpent géant]]** et du **Sparutor** (crocodilien CSV).
>
> Voir [[Bestiary/Index]] · [[Géographie]] · [[Serpent géant]] · [[Krill géant]] · [[Ruche d'insectes]]

---

## 1. Description géographique & climat

**Localisation principale** :
- **Pyrtara** (Ilthara) : marais ardents (proximité volcaniques), eaux saumâtres.
- **Marécages de Noyrath** (Ilthara) : marais sacrés-corrompus, **voile mince entre les mondes**.
- **Onara sud** : lacs marais tempérés (Foires des Vents adjacentes).
- **Vytharia** (Ilthara) : marais oniriques, rêve/réalité fluctuent (Voile du Rêve).

**Climat** :
- **Humidité 90%+** constante
- Chaleur tropicale (Pyrtara, Noyrath) ou tempérée modérée (Onara)
- Pluies fréquentes, longues
- Vapeurs et brumes chroniques
- Eau stagnante ou semi-courante

**Particularités** :
- **Eaux saumâtres** (souvent), tourbières, mangroves
- **Vapeurs sulfureuses** (Pyrtara — proximité volcanique)
- **Voiles oniriques** (Vytharia, Noyrath)
- **Brouillards permanents** sur miroirs d'eau
- **Phytoplancton** abondant (productivité primaire élevée)

**Spécificité marécageuse** :
- **Productivité primaire élevée** mais **biomasse répartie verticalement** (vase, eau, surface, canopée)
- **Embuscade aquatique** = méthode dominante
- **Cycles maladies** importants (moustiques, parasites)
- **Voile entre les mondes** (Vytharia, Noyrath) = créatures planaires possibles

## 3. Cycle saisonnier

| Saison | Phénomènes biologiques majeurs |
|--------|-------------------------------|
| **Saison des pluies** | Marais inondés, hauteurs d'eau extrêmes. Reproduction massive (poissons, grenouilles). Migrations aviens retour. Productivité primaire pic. |
| **Saison sèche** | Eaux retirées. Concentration animale autour des points d'eau. Sparutor à l'affût. Champignons abondants en zones boueuses. |
| **Saison des moustiques** | Pullulation insectes. Maladies en pic. Voyageurs évitent. Aviens insectivores prospèrent. |
| **Saison des migrations** | Oiseaux d'eau de passage. Échanges marécage-côte. Frontières floues avec écosystème côtier. |

**Événements signatures** :
- **Inondation cyclique** (saison pluies — événement majeur)
- **Pullulation moustiques** (impact santé humaine)
- **Voile mince** (Noyrath) = phénomène cosmique récurrent
- **Floraison de lotus** (signature visuelle)

## 4. Cycle ère cosmique

| Ère active | Effet sur l'écosystème Marais |
|-----------|-------------------------------|
| **Ère du Verdoiement** | **Productivité explose**. Roseaux deviennent forêt. Lotus géants. Variant **Verdoyant**. Espèces aquatiques mutées. |
| **Ère de la Brume Mortelle** | **Ère natale**. Brumes permanentes, eau noircie. Variant **Pourpre**. Algues d'ombre. Ossements rituels accumulés. Religion Vael'Kurash + Noctari prospèrent. |
| **Ère du Sommeil de Glace** | Marais gelés en surface (paradoxe). Vie réfugiée en profondeur. Sparutors en hibernation (rare). |
| **Ère des Échos Brisés** | Voile de Vytharia se confond avec marais réel. Variant **Spectral / Brisé**. Échos de créatures anciennes. |
| **Ère des Vents Bouleversants** | Vagues sur l'eau, brouillards déplacés. Migrations aviens spectaculaires. Plumes du Vent. |
| **Ère du Sommeil Onirique** | **Marais devient rêve**. Vytharia entre en mode actif. Variant **Onirique**. Communications oniriques avec faune. Religion Somnium Vigil prospère. |
| **Ère de l'Ombre Longue** | Marais nocturne 24h/24. Sparutors en chasse permanente. Variant **Shadow**. |
| **Ère du Rêve Lumineux** | Lumière dorée sur miroirs d'eau (paradoxe avec brumes). Variant **Doré** rare. |
| **Ère du Feu Endormi** | Pyrtara s'embrase. Marais bouillonnent. Variant **Brulé**. Frontière marais-volcan brouillée. |
| **Ère des Présages** | Reflets dans l'eau forment augures. Brouillards montrent visions. Variant **Vénérable**. |

> **Modulation forte** : le marais est l'écosystème **le plus connecté aux ères oniriques/spectrales** (Brume Mortelle, Sommeil Onirique, Échos Brisés). Vytharia + Noyrath = portails écologiques.

## 7. Équilibres écologiques fragiles

**Pivots critiques** :
1. **Sparutors / Serpents géants apex** — régulent poissons + sangliers de marais. Surchasse = explosion proies → producteurs détruits.
2. **Roseaux** — base structurelle (filtration eau, habitat). Coupe massive = effondrement.
3. **Voile mince de Noyrath** — équilibre cosmique. Perturbation = invasion planaire (cf. [[Plans cosmiques]]).
4. **Moustiques (paradoxalement)** — base prédateurs intermédiaires aviens. Sans eux, oiseaux affamés.

**Liens cosmiques** :
- **Noyrath** = nœud cosmique mineur (jonction vivants/morts).
- **Vytharia** = nœud onirique (Somnix, Tempora).
- **Pyrtara** = jonction marais-volcan (Feu + Eau, paradoxe).
- **Lac des Rêves** (Ilthara — voir [[Géographie]]) = lac sacré jonction.

## 8. Présence humanoïde & impact

**Activités humaines** :
- **Pyrtara** : dictature militaire, fortifications, exploitation marécages pour ressources alchimiques.
- **Vytharia** : oligarchie mystique, illusionnistes, **Voile du Rêve** rituel.
- **Druides Ackerna** (Ilthara — théocratie druidique) : protection des marécages sacrés.
- **Pêche traditionnelle** : Onara sud, paisible.
- **Tribus de Noyrath** *(rare)* : médiateurs entre vivants et morts.

**Sanctuaires religieux** :
- **Vael'Kurash** (mort) — sanctuaires à Noyrath, jonction.
- **Somnium Vigil** (rêves) — Vytharia, principale.
- **Foedus Animae** (âmes) — communion avec esprits des marais.
- **Rota Mundi** — cycles aquatiques.

**Conflits** :
- **Pyrtara expansionniste** vs **Ackerna protectrice** (Ilthara internal).
- **Métamorphes infiltrent communautés** (Vytharia danger constant).
- **Goblins en clans des ruines englouties**.
- **Démons mineurs** sortent occasionnellement de Noyrath.

**Quêtes typiques** :
- Affronter un Sparutor (boss régional)
- Récolter venin de Serpent géant (alchimie haute)
- Investiguer un voyageur disparu (Métamorphe ?)
- Traverser Noyrath (rituel Vael'Kurash)
- Percer le Voile du Rêve (Vytharia — Phase 4)
- Pêche de Krill géant (mission danger-récompense)
