# 🕳️ Plans cosmiques — Écosystème planaire

> Écosystème **non-terrestre**, **non-aquatique** — c'est l'**ailleurs**. Ne désigne pas un lieu fixe sur la carte d'Hybelior mais des **manifestations** : **Brèches du Néant** (jonctions vers le Vide), **Cratères du Cardinal** (sites où le Cardinal a frappé — cf. [[Le Souffle]]), **Failles de Tempora corrompues**, **Zones d'effondrement magique**. Domaine des entités cosmiques pures : [[Spectre des Ères]], [[Tisseur du Vide]], [[Démon mineur]], [[Esprit changeforme]], [[Élémentaire de feu]].
>
> Voir [[Bestiary/Index]] · [[Cosmologie]] · [[Le Souffle]] · [[Spectre des Ères]] · [[Tisseur du Vide]] · [[Démon mineur]] · [[Esprit changeforme]]

---

## 1. Description géographique & climat

**Localisation** : **non-géographique au sens classique**.

**Sites de manifestation** :
- **Cratères du Cardinal** : sites où le Cardinal a frappé lors d'un Souffle violent — terrain corrompu, plans superposés.
- **Brèches du Néant** : ouvertures vers le Vide. Apparaissent près de sites cosmiques (Mont Cendra, Pics des Vents Hurlants, Cœur de Givre).
- **Failles de Tempora corrompues** : ruptures temporelles (Échos Brisés permanents).
- **Zones d'effondrement magique** : académies de Lumasar accidentées, sites de bataille magique (Bataille des Mille Flèches résiduelle).
- **Voile du Rêve** (Vytharia, Ilthara) : jonction onirique-réel.
- **Lac des Rêves** (Ilthara) : jonction vivants-morts.

**Climat (variable selon plan)** :
- **Astral** : lumière sans source, gravité incohérente, sons amortis.
- **Éthéré** : matière transparente, fantomatique, déphasage.
- **Vide** : géométries impossibles, températures absurdes (chaleur+froid mêlés), absence directionnelle.
- **Infernal** : chaleur planaire, gaz, jonctions Démons.

**Particularités** :
- **Lois physiques relatives** (gravité, temps, lumière)
- **Présence cosmique constante** (entités-natifs)
- **Effets sur les visiteurs** (drain mental, illusions, vol de mémoire)
- **Récolte exceptionnelle** mais **dangereuse**

**Spécificité planaire** :
- **Trophicité d'énergie** (pas de matière classique)
- **Hiérarchie par CR cosmique** (les avatars dominent les entités mineures)
- **Cycles cardinaux** (Souffles régulent les populations)
- **Les visiteurs humains = proies potentielles** (drain mental, vol de mémoire, possession)

## 3. Cycle (non-saisonnier — cycles cosmiques)

| Cycle | Phénomènes majeurs |
|--------|-------------------|
| **Pulsation cardinale** | À chaque Souffle Cardinal majeur, les plans se réorganisent. Population planaire fluctue. |
| **Ouverture de Brèche** | Brèche du Néant s'ouvre — invasion mineure de Démons / Tisseurs. Sceaux nécessaires. |
| **Effondrement magique** | Académies subissent ruptures (Lumasar) — mini-plans temporaires. |
| **Convergence rituelle** | Druides de l'Écho (Ulinor), Foedus Animae, Vael'Kurash provoquent ouvertures contrôlées. |

**Événements signatures** :
- **Souffle Cardinal** = bouleversement majeur des plans
- **Apparition d'un Avatar** = événement apocalyptique
- **Convergence onirique** (Vytharia) = visions partagées
- **Voile mince activé** (Noyrath) = traversée vivants-morts possible

## 4. Cycle ère cosmique

| Ère active | Effet sur les Plans cosmiques |
|-----------|-------------------------------|
| **Ère de l'Ombre Longue** | Démons mineurs sortent. Brèches s'élargissent. Variant **Shadow** universel sur entités. |
| **Ère des Échos Brisés** | **Affinité forte avec [[Spectre des Ères]]**. Failles de Tempora s'amplifient. Variant **Spectral / Brisé**. |
| **Ère du Rêve Lumineux** | Esprits changeforme apparaissent en sanctuaires. Variant **Doré**. Eldoria stir. |
| **Ère du Sommeil Onirique** | **Voile du Rêve activé**. Vytharia s'étend. Variant **Onirique**. Somnix actif. |
| **Ère de la Brume Mortelle** | Brèches multiples. Démons et Tisseurs prolifèrent. Catastrophe planaire. |
| **Ère du Crépuscule** | **Ère apocalyptique** (cf. [[Les Ères]] arc). Tous les plans convergent. Avatars manifestent. |
| **Ère du Verdoiement** | Esprits naturels (Spiritus) prolifèrent en plans. Variant **Verdoyant** dans planar. |
| **Ère des Vents Bouleversants** | Plans déstabilisés (Aerion). Failles dispersées. |
| **Ère du Feu Endormi** | Démons infernaux abondants. Calor s'éveille. Variant **Brulé**. |
| **Ère du Sommeil de Glace** | Plans figés (rare). Variant **Frost**. |
| **Ère des Présages** | Tous les plans en augure. Fatum dominant. Variant **Vénérable**. |

> **Modulation extrême** : les plans cosmiques sont **les plus impactés par les ères cosmiques majeures** (Crépuscule = climax). Les Spectres et Démons sortent en masse pendant Échos Brisés, Ombre Longue, Brume Mortelle.

## 7. Équilibres écologiques fragiles

**Pivots critiques** :
1. **Sceaux des Brèches** — équilibre cosmique fondamental. Si rompus = invasion (cf. [[Le Souffle]] arc narratif).
2. **Avatars cosmiques** — leur présence régule les entités mineures. Si vaincus, chaos cosmique.
3. **Cycles cardinaux** — alternance Souffle/Ère. Si déréglés (Ère bloquée), désorganisation totale.
4. **Voiles** : Voile du Rêve (Vytharia), Voile mince (Noyrath) — fragiles, peuvent se déchirer.

**Liens cosmiques** :
- **Cardinal** = entité tutélaire (cf. [[Le Souffle]] §Cardinal).
- **Cosmiques** = patrons des plans (Vortex, Etherius, Tempora, Noctis, etc.).
- **Cosmologie** complète = voir [[Cosmologie]].
- **Tempora blessée** = source d'instabilité actuelle.
- **Noctis croissant** = pression sur tous les plans.
- **Eldoria endormie** = potentiel de réveil planaire majeur.

## 8. Présence humanoïde & impact

**Activités humaines** *(rare, dangereux, expert)* :
- **Druides de l'Écho** (Ulinor-Nylor) : ouvertures rituelles contrôlées.
- **Vael'Kurash** : nécromancie + plans des morts.
- **Foedus Animae** : communion avec esprits.
- **Somnium Vigil** : navigation onirique (Vytharia).
- **Académies de Lumasar** : recherche cosmique (accidents).
- **Pacte démoniaque** : contrats avec [[Démon mineur]] (Phase 4).

**Sanctuaires religieux** :
- **Toutes les religions cosmiques** ont des liens : Ordo Caelum (Celestia), Vael'Kurash (mort), Noctari (ombre), Foedus Animae (âmes), Somnium Vigil (rêves).
- **Conditions cachées 🔒** d'Ères = quêtes planaires (cf. [[Les Ères]]).

**Conflits** :
- **Démons sortis** vs Aventuriers sceleurs.
- **Tisseurs du Vide** vs Druides.
- **Spectres** vs Foedus Animae.
- **Joueurs Accord élevé** = peuvent négocier avec entités cosmiques.

**Quêtes typiques** :
- Sceller une Brèche du Néant (urgence régionale)
- Affronter un Avatar cosmique (apocalyptique — Phase 4)
- Pacte avec un Démon (gameplay moral)
- Traverser le Voile du Rêve (Vytharia — Phase 4)
- Communier avec un Esprit changeforme (gardien sacré)
- Récupérer un Sceau brisé d'une ère passée
- Rituel de Souffle Cardinal contrôlé (haut niveau)
- Lutte contre un Tisseur du Vide effondrant la réalité
