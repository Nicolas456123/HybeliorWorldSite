# Planche en frêne

## Description

Planche en frêne — bois souple résistant aux chocs. Préféré pour les **manches d'armes** (lances, marteaux).

## Recette / source

```yaml
intrants: [Bois de frêne × 2]

sortie: 4 planches en frêne T2
```
