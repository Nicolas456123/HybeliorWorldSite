# Bliysium

## Description

Alliage **léger résonant** — mithril + argent + cristal de Voie fusionnés. Confère *Résonance d'âme* (+Mana/hit) gratuit. Préféré pour les focus magiques et les armes de Lié-chevalier.

## Recette / source

```yaml
intrants: [Lingot de mithril × 2, Lingot d'argent × 2, Cristal de Voie × 1]
durée: 720 s
sortie: 1 Lingot de Bliysium T4
```

Prix : 500 Éclats.

## Crafts destinés

Épée magistrale Bliysium, Fleuret du Maître d'Armes, sceptres, Cometfall (T5 cristal+Bliysium).
