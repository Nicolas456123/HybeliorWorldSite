## 5 classes canoniques

- **Tissu** : Mage / Lié — défense magique +50%, physique −50%, conduit Voie élevé
- **Cuir** : Éclaireur / Voleur — agilité préservée, esquive +
- **Mailles** : Soldat polyvalent — équilibre central
- **Plate** : Tank / Chevalier — défense max, mobilité réduite, anti-Voie −25%
- **Spécial-Exotique** : Endgame, drop boss, affixe créature unique
