# 🎗 Bandeau frontal / Reliure — Focus magique discret

> Tissu enchanté, fil ou cordelette autour du front. **Focus discret** ; bonus +**Mémoire** + +**Esprit**, réduction du temps d'incantation, accélération d'apprentissage des Maîtrises. Compatible capuche tissu, exclusif avec heaume/casque plate. Hérite du pattern canonique [[Tome]].

---

## 1. Vue d'ensemble

### Concept

Le **Bandeau frontal** (ou **Reliure**) est un tissu — souvent rituel, soyeux, brodé de glyphes — porté autour du front du personnage. Mécaniquement, c'est le **focus magique le plus discret** : aucune main occupée, aucune voyance ostentatoire, aucun pacte cosmique. Il offre un **bonus passif modéré** centré sur la **Mémoire** (apprentissage, capacité d'inscription) et l'**Esprit** (régénération mana, efficacité magique de fond), ainsi qu'une **réduction du temps d'incantation** des sorts (le focus aide la concentration).

C'est l'item de prédilection des **érudits**, **scribes**, **enchanteurs en exercice**, **mages discrets** qui ne veulent pas afficher leur Voie. Compatible avec la plupart des têtes (capuche tissu, bandeau seul) ; **incompatible** avec heaume/casque rigide (plate/mailles lourdes).

### Conflit slot Tête — règle d'arbitrage

> Le Bandeau frontal occupe un **slot front** distinct du slot tête (casque/capuche), avec règles de compatibilité :

| Item de tête équipé | Compatibilité Bandeau |
|----------------------|------------------------|
| Aucun (tête nue) | Compatible |
| Capuche tissu (légère) | Compatible (le bandeau passe sous ou intégré à la capuche) |
| Capuche cuir (légère) | Compatible (visible à la lisière de la capuche) |
| Casque mailles | Compatible (porté sous le casque, non visible) |
| Heaume plate / casque rigide | **Incompatible** (le heaume couvre tout le front, le bandeau ne tient pas) |
| Couronne / diadème | Compatible (le bandeau passe en dessous, double signature noble) |

> Cette règle structure les builds : un mage tissu/cuir peut cumuler Capuche + Bandeau (2 bonus). Un tank plate ne peut **pas** porter de Bandeau.

### Synergie avec les autres slots

- **Bandeau + Tome** : combo phare érudit — Mémoire boostée, sorts du Tome incantés plus vite.
- **Bandeau + Orbe** : régen Mana du Bandeau soutient l'amplification de l'Orbe.
- **Bandeau + Anneau de Voie** : focus discret sur la Voie spécifique, bonus apprentissage Maîtrise +X% (cf. §6).
- **Bandeau + Capuche tissu** : double bonus discrétion (mage furtif).

### Bandeau vs autres focus — comparatif

| Trait | **Bandeau** | **Tome** | **Orbe** | **Talisman** |
|-------|-------------|----------|----------|---------------|
| Slot | Front (mains libres) | Main libre | Main libre | Cou ou ceinture |
| Effet primaire | +Mémoire/+Esprit, -temps incantation | Sorts encapsulés | Amplification Voie | 1 sort à charges illimitées |
| Discrétion | **Maximale** | Faible (livre visible) | Faible (sphère brillante) | Variable |
| Cible joueur | Érudit, mage discret | Mage polyvalent | Mage spécialiste | Pactiste |
| Coût production | Modéré | Élevé | Élevé | Élevé |
| Mains libres ? | **Oui** (les deux) | Non (1 main occupée) | Non (1 main occupée) | Oui |

> Le Bandeau est le **seul focus magique** qui laisse les **2 mains libres** (avantage majeur pour double-arme + magie).

> [!important] Plafond de réduction d'incantation
> La réduction de temps d'incantation cumulée (Bandeau + autres affixes éventuels) **plafonne à -50%** (cf. [[Combat]]). Au-delà, les pertes deviennent diminishing returns puis nulles.

> [!important] Plafond global stats accessoires
> Le Bandeau **ne compte pas** dans le plafond +30% des accessoires (il est focus magique, pas accessoire). Mais un cumul *Bandeau + Anneau + Amulette* tous orientés Mémoire respecte ses propres limites de stat (cf. [[Personnage]]).

### Durabilité

> Le Bandeau est en **tissu**, donc subit l'usure (contrairement aux focus minéraux/métalliques). Réparation par Tisserand ou Couturier (Maintenance, [[Crafts]] §Tissage). Peut se déchirer en combat (proba faible mais non nulle pour les Bandeau Commun-Œuvré ; Magistral+ tissus magiques résistants).

### Rouille post-Souffle

Bandeau Magistral+ : **−10% sur 2 semaines**. Les bonus Mémoire/Esprit sont les premiers affectés.

## 4. Système d'enchantement

> Pattern [[Tome#4. Système d'enchantement (inscription des sorts)|Tome §4]] adapté.

### Comment un Bandeau est créé

```
[Tissu vierge] (Tisserand)
    → Lin / soie / tissu rituel selon tier
    ↓
[Bandeau brodé] (Couturier)
    → Forme adaptée (bandeau / reliure / diadème), broderie de base
    ↓
[Cercle d'enchantement] (Enchanteur)
    → Inscription d'affixes : glyphes brodés, fils de Cristal de Voie tissés
    ↓
[Bandeau enchanté]
```

### Modulation par l'Accord

- Enchanteur Accord ≥75% : -10% coût rituel, +5% efficacité
- Porteur Accord ≥75% : +5% bonus Mémoire/Esprit, -3% temps incantation supplémentaire
- Porteur Accord ≤25% : -10% efficacité

### Désenchantement

Récupération ~30-50% du cristal. Le tissu est récupérable (recyclable par Tisserand).

## 10. Décisions ouvertes / chantiers de profondeur

- **Conflit slot tête** : confirmé règle (compatible tissu/cuir/mailles, exclusif plate). À valider en UX visualisation 3D.
- **Plafond -50% temps incantation** : confirme-t-on ce plafond global ? Cumul Bandeau + Affixes Tome + autres pourrait l'atteindre rapidement.
- **Mémoire prodigieuse** : +X% gain XP sur 1 Maîtrise — équilibrer avec économie de progression. Trop fort ?
- **Apprentissage accéléré toutes Maîtrises** : -25% si non cumulable avec *Mémoire prodigieuse* ? Confirmer règle d'exclusion.
- **Bandeau dans capuche** : visibilité — branche UX.
- **Reliure dans diadème noble** : double-couche fonctionnelle (focus magique + statut social) — playtest pour balance.
- **Bandeau qui se déchire en combat** : règle pour Tiers 1-3 ? Realisme vs frustration.
