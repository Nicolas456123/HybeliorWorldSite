# Potion de régen Mana

## Description

Liquide bleu translucide qui scintille faiblement. Distillé à partir de plantes alchimiques chargées et d'un éclat de Cristal de Voie broyé. **Ne fonctionne que si une Voie est active** — sinon, l'effet est gaspillé.
