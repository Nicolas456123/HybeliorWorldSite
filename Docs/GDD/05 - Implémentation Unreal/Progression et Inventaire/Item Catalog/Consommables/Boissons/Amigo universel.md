# Amigo universel

## Description

Cocktail multicolore servi en ronde dans les tavernes — chaque buveur en prend une gorgée et passe le verre. Symbole de **fraternité** entre étrangers. Dans certaines villes, refuser l'Amigo est un affront grave.
