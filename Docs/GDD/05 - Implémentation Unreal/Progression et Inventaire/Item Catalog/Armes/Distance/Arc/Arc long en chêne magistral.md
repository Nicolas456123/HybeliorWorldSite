# Arc long en chêne magistral

## Description

Arc long lamellé (~1.85m) — composé de plusieurs essences de bois superposées : chêne (cœur), if (face dorsale), corne de bovidé (face ventrale). Standard du **tireur d'élite** des armées d'Endora.

## Stats

Dégâts 60 · Traction 1.8s · Portée 50m · Critique +8% · Durabilité 380

- 1 Commun : *Perçant +10%*
