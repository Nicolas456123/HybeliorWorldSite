# Dague jumelle des ombres

## Description

Paire de dagues identiques, taillées dans le même bloc d'acier d'Ivar coulé en deux moules — chacune **chante quand l'autre est dégainée**. Forgées pour les danseuses-rituelles d'Ilthara qui combattent en miroir. Les jumelles ne se séparent jamais : si l'une est perdue, l'autre devient ternie.

## Stats (par dague — paire)

Dégâts 84 · Vitesse 1.72 · Crit 8% (mult ×1.5) · Stagger 25 · Durabilité 580

## Affixes notables

- *Critique base ×1.5* natif (cumul ×1.95 avec affixe rare)
- *Variant Shadow* permanent (+15% dégâts cible en mouvement)
- *Saignement profond*
- *Multiplicateur critique +40%*
- 1 Très rare *paire* : *Synergie jumelle* — quand les deux dagues frappent dans la même seconde, le second coup est crit garanti
