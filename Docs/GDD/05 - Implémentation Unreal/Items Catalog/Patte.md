# 🐾 Patte — Archétype ressource créature

> Membre locomoteur (mammifère, reptile, avienne, crustacé) prélevé entier après dépeçage articulaire. Combine **cuir spécial** (peau plantaire renforcée) + **os** + **griffes/serres** (sous-types — voir [[Griffe]]). Sert de talisman, manche d'outil mou, sac petit, et — pour les pattes signature — composant rituel.
>
> Voir [[Sources de Ressources]] §Récolte créature · [[Crafts]] §Travail du cuir · [[Griffe]] · [[Os]]

---

## 1. Vue d'ensemble

La **Patte** est un membre **multi-matériau** : peau dense (cuir spécial très résistant — *Patte de Loup*), os, griffes/serres, parfois fourrure ou plume. Récoltée **entière** (l'articulation préservée) ou **désarticulée** (composants séparés au choix du joueur).

Trois usages canoniques :
1. **Cuir spécial** — la peau plantaire est plus résistante que le cuir dorsal (× 1.5 défense)
2. **Talisman** — patte séchée comme amulette (folklore : porte-chance, voir Trinoria/Onara)
3. **Manche d'outil organique** — patte d'ours pour manche de masse rituelle

---

## 2. Variations / origines créatures

### Mammifères
- [[Loup forestier]] : Patte de loup → cuir spécial souple (talisman pisteur)
- [[Ours brun]] : Patte d'ours → cuir massif, manche cérémoniel (totem Skaldoria)
- [[Sanglier]] : Pied de sanglier → cuisson, talisman commun
- [[Cerf majestueux]] : Sabot + pied → focus magique léger (folklore druidique Onara)

### Aviens (serres)
- [[Aigle royal]] : Serre d'aigle → talisman de chasse, sertis bracelet
- [[Faucon]] : Serre de faucon → broche signature aviateur

### Aquatiques / Crustacés
- [[Krill géant]] : Pince de krill (sous-type Patte) → outil de découpe
- [[Tortue ancestrale]] : Patte de tortue → cuir extrêmement résistant

### Démoniaque
- [[Démon mineur]] : Patte griffue → talisman de Voie de Noctis (corrompu)

## 4. Drop / Récolte

| Critère | Détail |
|---------|--------|
| **Métier** | Dépéceur (sous-Maîtrise *Dépeçage articulaire*) |
| **Palier minimum** | Novice (T1-T2), Initié (T3), Adepte (T4), Expert (T5) |
| **Outil requis** | Scie d'os ou Couteau de tanneur ; Pince articulaire (T3+) |
| **Drop rate** | 40-60 % par patte (1-4 pattes selon créature) — choix joueur : entière ou décomposée |
| **Mini-jeu** | Désarticulation à l'épaule/hanche ; un échec = patte fendue (perte fourrure ou cuir) |
| **Modificateur** | × 1.5 vétéran ; × 2 alpha/colosse |

> **Décomposition** : si le joueur préfère, la patte peut être **désarticulée** en : Cuir spécial + Os + Griffe + (Fourrure ou Plume) — drop répartis selon la créature.

## 8. Décisions ouvertes

- **Décomposition vs entière** : laisser le choix joueur ? **Proposition** : oui, mini-jeu au moment du dépeçage.
- **Sous-types** : Serres (aviens) sont-elles taggées Patte ou Griffe ? **Proposition** : composante de Patte, drop séparé Griffe.
- **Drop rate variable par patte** : un loup a 4 pattes, drop 1-4 (random) ; un démon ailé a 2 pattes ; un krill a 8 pinces.
- **Talisman folklore** : tag culturel par nation (Skaldoria = ours, Onara = cerf, Galenor = aigle) — Phase 4.
