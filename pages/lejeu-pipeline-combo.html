Étape 1 — Définir un Moveset d'arme

UHWWeaponMoveset · FHWComboChain · FHWComboAttack
Chaque arme possède un Moveset définissant ses combos et animations

UHWWeaponMoveset est un UPrimaryDataAsset qui regroupe toutes les chaînes de combo, les compétences et les animations associées à un type d'arme. Le type d'arme est défini par l'enum EHWWeaponType : Sword, Axe, Mace, Dagger, Bow, Staff, Spear, Shield.

Chaque moveset contient un tableau de FHWComboChain décrivant les enchaînements possibles, ainsi que les montages d'animation pour les états idle, dégainage et rengainage.

WeaponType EHWWeaponType — Type d'arme parmi les 8 catégories (Sword, Axe, Mace, Dagger, Bow, Staff, Spear, Shield).
ComboChains TArray<FHWComboChain> — Tableau de toutes les chaînes de combo disponibles pour cette arme.
WeaponSkills Compétences spéciales liées à l'arme — débloquées progressivement avec la maîtrise.
BaseAttackSpeed / AttackRange Vitesse d'attaque de base et portée de l'arme — modifiées par les bonus de maîtrise.
IdleStanceMontage / DrawMontage / SheatheMontage Montages d'animation pour la posture de combat, le dégainage et le rengainage de l'arme.
— Structure FHWComboChain —

ComboName — Nom de la chaîne de combo (ex : "Enchaînement léger", "Frappe lourde"). ComboTag — FGameplayTag identifiant le type de combo : Combo.Light, Combo.Heavy ou Combo.Special.

Attacks — TArray<FHWComboAttack>, séquence ordonnée des attaques composant la chaîne. Finisher — FHWComboAttack, attaque finale déclenchée après la dernière attaque de la chaîne.

RequiredMasteryLevel — Niveau de maîtrise minimum requis pour accéder à cette chaîne de combo.

— Structure FHWComboAttack —

AttackMontage — Montage d'animation joué pour cette attaque. DamageMultiplier — Multiplicateur de dégâts appliqué au calcul de base. DamageType — FGameplayTag définissant le type de dégât (physique, élémentaire, etc.).

ComboWindowDuration — Durée de la fenêtre pendant laquelle le joueur peut enchaîner l'attaque suivante. StaminaCost — Coût en endurance pour exécuter cette attaque. RequiredMasteryLevel — Niveau de maîtrise minimum pour débloquer cette attaque individuelle.

HiddenUnlockCondition — Condition cachée à remplir pour révéler cette attaque (non affichée au joueur). OnHitEffect — Effet appliqué à l'ennemi lors d'un touché confirmé. bCanCharge / ChargedMultiplier — Si l'attaque peut être chargée et le multiplicateur associé.

Étape 2 — Configurer la maîtrise

UHWWeaponMasteryComponent · FHWWeaponMasteryData · Formule XP
Chaque type d'arme possède sa propre progression de maîtrise

UHWWeaponMasteryComponent est un composant répliqué qui gère la maîtrise de toutes les armes du personnage. Il contient un TArray<FHWWeaponMasteryData> avec une entrée par type d'arme, initialisée au niveau 0 dans BeginPlay pour les 8 types.

L'expérience requise pour monter de niveau suit une courbe exponentielle : 100.0f * Pow(1.15f, Level). La maîtrise n'a pas de plafond fixe mais commence à 0 et peut dépasser 100.

WeaponType EHWWeaponType — Type d'arme associé à cette entrée de maîtrise.
MasteryLevel Niveau actuel de maîtrise (0 à 100+) — débloque progressivement des combos et attaques.
CurrentExperience / ExperienceToNextLevel XP accumulée et seuil pour le prochain niveau — formule : 100.0f * Pow(1.15f, Level).
DamageMultiplier Multiplicateur de dégâts passif : 1.0 + Level * 0.02 — +2% par niveau de maîtrise.
AttackSpeedBonus Bonus de vitesse d'attaque : Level * 0.5 — augmente la fluidité des enchaînements.
CritRateBonus Bonus de taux de critique : Level * 0.1 — +0.1% de chance de critique par niveau.

Étape 3 — Équiper une arme

Player Blueprint · ComboComponent · Weapon Mesh
L'équipement d'une arme active son moveset dans le ComboComponent

Lorsque le joueur équipe une arme, le Player Blueprint met à jour le mesh visible (ex : Sword_Mesh, Shield_Mesh, Bow) sur les composants correspondants de l'acteur.

Le Blueprint appelle ensuite ComboComponent->SetActiveMoveset(NewMoveset), ce qui réinitialise l'état de combo courant (index, tag, fenêtre) et charge le nouveau moveset comme référence active.

Weapon (USceneComponent) Point d'attache racine pour les composants d'arme sur le squelette du personnage. Composant · Attache
Sword_Mesh (USkeletalMeshComponent) Mesh squelettique de l'épée — rattaché au socket de la main droite du personnage. Mesh · SkeletalMesh
Shield / Shield_Mesh Composant et mesh du bouclier — rattaché au socket de la main gauche. Mesh · Bouclier
SetActiveMoveset(NewMoveset) Réinitialise CurrentComboIndex, CurrentComboTag et la fenêtre de combo, puis charge le nouveau moveset. ComboComponent

Étape 4 — Input d'attaque

Input_WeaponLeft · Combat.State · GameplayAbility
L'input du joueur est routé vers la bonne ability selon l'arme équipée

Input_WeaponLeft() vérifie d'abord si le tag Combat.State.ReadyToFight est actif. Si le joueur n'est pas en posture de combat, l'ability GA_ReadyToFight est activée pour passer en mode combat.

Si le joueur est prêt, le système vérifie le tag de set de combat pour router vers la bonne ability : Combat.Set.Unarmed active GA_UnarmedAttack, Combat.Set.Bow active GA_BowShoot, Combat.Set.SwordAndShield active GA_SwordAttack.

Input_WeaponLeft() Point d'entrée de l'attaque — vérifie l'état de combat et route vers l'ability appropriée.
Combat.State.ReadyToFight FGameplayTag — Indique que le joueur est en posture de combat, arme dégainée.
GA_SwordAttack GameplayAbility Blueprint — Appelle ComboComponent->TryAttack(ComboTag) pour lancer le combo.
Combat.Set.* Tags de set de combat (Unarmed, Bow, SwordAndShield) déterminant l'ability à activer.

Étape 5 — Exécution du combo

TryAttack · ComboWindow · PlayAttackMontage
TryAttack orchestre la validation, la sélection et l'exécution de chaque attaque

La méthode TryAttack(FGameplayTag ComboTag) est le coeur du système de combo. Elle valide le moveset actif, vérifie la maîtrise, sélectionne l'attaque appropriée dans la chaîne et gère la fenêtre d'enchaînement.

Si la fenêtre de combo expire sans nouvel input, OnComboWindowExpired est déclenché, ce qui appelle ResetCombo et broadcast OnComboReset.

1. Valider le Moveset Vérifie que ActiveMoveset est valide et recherche la FHWComboChain correspondant au ComboTag fourni. Validation
2. Vérifier la maîtrise Contrôle que MasteryLevel est supérieur ou égal au RequiredMasteryLevel de la chaîne. Maîtrise
3. Filtrer les attaques accessibles GetAccessibleAttacks filtre par niveau de maîtrise et par HiddenUnlockCondition tag. Filtrage
4. Déterminer l'index suivant Si bInComboWindow + même tag : CurrentComboIndex + 1. Tag différent ou pas de fenêtre : reset à 0. Index
5. Sélectionner attaque ou Finisher Si l'index dépasse la longueur de la chaîne, le Finisher est sélectionné à la place. Sélection
6. Vérifier l'endurance HasEnoughStamina() vérifie le coût, puis ConsumeStamina(StaminaCost) déduit l'endurance. Stamina
7. Mettre à jour l'état Met à jour CurrentComboIndex et CurrentComboTag, puis démarre le ComboWindowTimer. État
8. Jouer l'animation PlayAttackMontage(SelectedAttack) lance le montage. Broadcast OnComboAttack ou OnComboFinished. Animation · Delegates

Étape 6 — Détection de touche

AnimNotify · Melee Trace · Mastery XP
Un AnimNotify dans le montage déclenche la détection de collision

Pendant l'animation d'attaque, un AnimNotify placé dans le montage déclenche un melee trace ou un hitbox sweep pour détecter les cibles touchées.

Lorsqu'un touché est confirmé, NotifyHitConfirmed() attribue de l'XP de maîtrise : +10 XP par touché. L'appel est routé vers CachedMasteryComponent->AddMasteryExperience(ActiveMoveset->WeaponType, 10.f).

AnimNotify Notification placée dans le montage d'attaque — déclenche la fenêtre de détection de collision.
Melee Trace / Hitbox Sweep Trace physique le long de l'arme ou sweep d'une zone pour détecter les acteurs touchés.
NotifyHitConfirmed() Callback de touché confirmé — attribue +10 XP de maîtrise au type d'arme actif.
AddMasteryExperience(WeaponType, 10.f) Ajoute l'XP au UHWWeaponMasteryComponent — déclenche les montées de niveau si le seuil est atteint.

Étape 7 — Calcul de dégâts

UHWGameplayEffectExecutionCalc · Crit · Réaction élémentaire
Le calcul de dégâts combine statistiques, critiques et réactions élémentaires

UHWGameplayEffectExecutionCalc capture les attributs Attack, Defense, MaxHealth, CritRate et CritDamage de la source et de la cible pour calculer les dégâts finaux.

Un encodage pair/impair du dégât final est utilisé pour indiquer un critique à l'UI sans envoyer de données supplémentaires.

BaseDamage Formule : Attack + Defense + MaxHealth — combinaison des statistiques capturées.
Crit Roll FRand() <= CritRate / 100 — si le jet réussit, CritDamage = BaseDamage * (CritDamage / 100).
ReactionMultiplier Multiplicateur obtenu via CheckReaction() — dépend des conditions élémentaires actives sur la cible.
FinalDamage Floor((BaseDamage + CritDamage) * ReactionMultiplier) — arrondi au sol, encodage pair/impair pour les critiques.

Étape 8 — Réactions élémentaires

UHWElementalReactionSystem · CheckReaction · ApplyReaction
Les réactions élémentaires combinent le type de dégât entrant avec les conditions actives

UHWElementalReactionSystem::CheckReaction prend en entrée le IncomingDamageType et les TargetConditions pour déterminer la réaction déclenchée. La méthode retourne un FHWElementalReactionResult contenant le type de réaction et le multiplicateur.

ApplyReaction() consomme la condition élémentaire utilisée et applique éventuellement une nouvelle condition sur la cible.

Vaporize Fire + Wet — Multiplicateur 1.5x. L'eau s'évapore au contact du feu, amplifiant les dégâts. Feu + Eau · 1.5x
Melt Fire + Frozen — Multiplicateur 1.3x. Le feu fait fondre la glace, libérant de l'énergie thermique. Feu + Glace · 1.3x
Freeze Ice + Wet — Gèle la cible en place. Pas de multiplicateur direct, mais immobilise l'ennemi. Glace + Eau · CC
ElectroCharge Lightning + Wet — Multiplicateur 1.2x. L'eau conduit l'électricité pour des dégâts amplifiés. Foudre + Eau · 1.2x
Overload Fire + Charged — Multiplicateur 1.5x avec explosion AoE (rayon 500). Dégâts de zone dévastateurs. Feu + Chargé · 1.5x AoE
Superconduct Ice + Charged — Réduit la défense de 30% sur la cible. Prépare des combos physiques dévastateurs. Glace + Chargé · -30% Def
Shatter Physical + Frozen — Multiplicateur 2.0x. Briser une cible gelée inflige des dégâts massifs. Physique + Gelé · 2.0x

Étape 9 — Progression de maîtrise

AddMasteryExperience · RecalculateMasteryBonuses · Level-Up
L'XP accumulée déclenche des montées de niveau et recalcule les bonus

AddMasteryExperience(WeaponType, XP) ajoute l'expérience à l'entrée correspondante. Une boucle while gère les montées de niveau successives si l'XP dépasse plusieurs seuils d'un coup.

À chaque montée de niveau, RecalculateMasteryBonuses recalcule les trois bonus passifs et notifie le UHWProgressionComponent du changement.

AddMasteryExperience(WeaponType, XP) Ajoute l'XP à CurrentExperience — boucle while pour gérer les level-ups multiples.
RecalculateMasteryBonuses DamageMultiplier = 1.0 + Level * 0.02, AttackSpeedBonus = Level * 0.5, CritRateBonus = Level * 0.1.
UHWProgressionComponent Notifié lors de chaque montée de niveau de maîtrise — peut déclencher des récompenses ou déblocages.

Étape 10 — Persistance de la maîtrise

SaveWeaponMastery · LoadWeaponMastery · OWS Backend
Les données de maîtrise sont sérialisées en JSON et sauvegardées via OWS

SaveWeaponMastery() sérialise toutes les entrées de maîtrise en JSON au format {"Masteries": [{WeaponType, MasteryLevel, CurrentExperience, ...}]}. LoadWeaponMastery(JSON) effectue l'opération inverse et appelle SetAllMasteryData().

La sauvegarde est transmise au backend OWS via AddOrUpdateCustomCharacterData("WeaponMastery", JSON). Cette opération fait partie de SaveAllProgression() qui sauvegarde également les quêtes, la progression et la barre de compétences.

SaveWeaponMastery() Sérialise les FHWWeaponMasteryData en JSON — appelé lors de la sauvegarde globale.
LoadWeaponMastery(JSON) Désérialise le JSON et appelle SetAllMasteryData() pour restaurer l'état complet.
AddOrUpdateCustomCharacterData Appel API OWS avec la clé "WeaponMastery" et le JSON sérialisé.
SaveAllProgression() Sauvegarde globale : maîtrise d'arme + quêtes + progression + barre de compétences.
